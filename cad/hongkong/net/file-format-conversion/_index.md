## 如何使用 Aspose.CAD 轉換 DWF 為 PDF？
`Image` 是代表記憶體中 CAD 文件的核心 Aspose.CAD 類別。  
使用 `Image` 類別載入 DWF 檔案，設定所需的 PDF 選項，然後呼叫 `Save`。此單行操作會保留向量資料、圖層與註解，產生與原始圖紙完全相同的 PDF。轉換會保留所有向量圖形、文字與線寬，確保 PDF 適合列印與電子分發。

## 如何從 CAD 檔案匯出 BMP 圖像？
`BmpOptions` 定義 BMP 輸出的設定，如解析度、色彩深度與壓縮方式。  
呼叫 `Image.Save` 方法並傳入 `BmpOptions`，可選擇調整寬度、高度與解析度。函式庫會將 3‑D 模型光柵化為點陣圖，讓您完整掌控圖像品質與色彩深度。您亦可指定 DPI，並在 24‑bit 或 32‑bit 色彩模式間選擇，以符合專案需求。

## 常見問題與解決方案

- **缺少字型或線型**：確保 DWF 包含所有參考資源，或使用 `LoadOptions` 內嵌它們。  
- **大型檔案超出記憶體**：使用 `Image.Load(stream, LoadOptions)` 並搭配 `LoadOptions.MemoryLimit` 以降低 RAM 使用量。  
- **BMP 顏色失真**：確認 `BmpOptions` 的 `BitsPerPixel` 設為 24 或 32，以獲得真彩色輸出。

## 常見問答

**Q: 我可以批次將多個 DWF 檔案轉換為 PDF 嗎？**  
A: Yes – iterate over a folder, load each file with `Image.Load`, and call `Save` with PDF options inside the loop.

**Q: BMP 匯出是否保留 3‑D 深度感？**  
A: The rasterizer creates a flat bitmap, but you can enable shading and lighting via `RasterizationOptions` for realistic depth.

**Q: 開發版需要授權嗎？**  
A: A temporary evaluation license works for development; a full license is mandatory for production deployments.

**Q: 支援哪些平台？**  
A: Windows, Linux, and macOS are all supported when running .NET Core or .NET 5+ runtimes.

**Q: Aspose.CAD 如何處理受密碼保護的 DWF 檔案？**  
A: Provide the password through `LoadOptions.Password` when loading the source file.
