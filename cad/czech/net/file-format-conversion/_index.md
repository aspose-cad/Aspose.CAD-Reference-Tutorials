# Konverze formátů souborů

## Úvod

Pokud potřebujete **převést DWF na PDF** rychle a zachovat každou čáru, křivku i anotaci, jste na správném místě. V tomto tutoriálu projdeme dva běžné scénáře s Aspose.CAD pro .NET: převod DWF návrhu do univerzálně zobrazitelného PDF a export 3‑D CAD výkresu do formátu BMP. Uvidíte, proč je Aspose.CAD špičkovou volbou pro konverzi CAD formátů, naučíte se praktické kroky a získáte tipy, jak se vyhnout častým úskalím.

## Rychlé odpovědi
- **Může Aspose.CAD převést DWF na PDF?** Ano – jediným voláním metody se celý proces provede.  
- **Je export BMP podporován pro 3‑D CAD?** Rozhodně, s nastavitelným rozlišením a barevnou hloubkou.  
- **Potřebuji licenci pro produkční použití?** Vyžaduje se komerční licence; k vyzkoušení je k dispozici bezplatná zkušební verze.  
- **Které verze .NET jsou kompatibilní?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7.  
- **Jaký je typický výkon?** Převod 200‑stránkového DWF na PDF trvá méně než 2 sekundy na standardním serveru.

## Co je Aspose.CAD pro .NET?
Aspose.CAD pro .NET je .NET knihovna, která umožňuje programatický **převod CAD souborů** bez nutnosti nativního CAD softwaru. Podporuje více než 30 vstupních a výstupních formátů, zpracovává stovky stránek v paměťově úsporných streamech a garantuje pixel‑perfektní vykreslení.

## Jak převést DWF na PDF pomocí Aspose.CAD?

`Image` je hlavní třída Aspose.CAD představující CAD dokument v paměti.  
Načtěte svůj DWF soubor pomocí třídy `Image`, nastavte požadované PDF možnosti a zavolejte `Save`. Tato jednorázová operace zachová vektorová data, vrstvy i anotace a vytvoří PDF, které vypadá přesně jako původní výkres. Konverze zachovává všechny vektorové grafiky, text a tloušťky čar, což zajišťuje, že PDF je vhodné pro tisk i elektronické šíření.

## Jak exportovat BMP obrázky z CAD souborů?

`BmpOptions` definuje nastavení pro BMP výstup, jako je rozlišení, barevná hloubka a komprese.  
Zavolejte metodu `Image.Save` s `BmpOptions`, případně upravte šířku, výšku a rozlišení. Knihovna rasterizuje 3‑D model do bitmapy, čímž vám poskytuje plnou kontrolu nad kvalitou obrazu a barevnou hloubkou. Můžete také specifikovat DPI a zvolit mezi 24‑bitovým nebo 32‑bitovým barevným režimem podle požadavků vašeho projektu.

## Časté problémy a řešení

- **Chybějící fonty nebo typy čar**: Ujistěte se, že DWF obsahuje všechny odkazované zdroje, nebo je vložte pomocí `LoadOptions`.  
- **Velké soubory překračují paměť**: Použijte `Image.Load(stream, LoadOptions)` s `LoadOptions.MemoryLimit`, aby byl odběr RAM nízký.  
- **Barevná deformace BMP**: Ověřte, že `BmpOptions` `BitsPerPixel` je nastaven na 24 nebo 32 pro výstup ve skutečných barvách.

## Často kladené otázky

**Q: Mohu hromadně převádět více DWF souborů do PDF?**  
A: Ano – projděte složku, načtěte každý soubor pomocí `Image.Load` a zavolejte `Save` s PDF možnostmi uvnitř smyčky.

**Q: Zachovává export BMP 3‑D hloubkové indicie?**  
A: Rasterizér vytvoří plochou bitmapu, ale můžete povolit stínování a osvětlení pomocí `RasterizationOptions` pro realistickou hloubku.

**Q: Je licence vyžadována pro vývojové sestavy?**  
A: Dočasná evaluační licence funguje pro vývoj; plná licence je povinná pro produkční nasazení.

**Q: Jaké platformy jsou podporovány?**  
A: Windows, Linux i macOS jsou podporovány při běhu na .NET Core nebo .NET 5+ runtime.

**Q: Jak Aspose.CAD zachází s DWF soubory chráněnými heslem?**  
A: Heslo předáte pomocí `LoadOptions.Password` při načítání zdrojového souboru.
