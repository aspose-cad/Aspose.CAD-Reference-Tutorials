## Cara Mengonversi DWF ke PDF dengan Aspose.CAD?

`Image` adalah kelas inti Aspose.CAD yang mewakili dokumen CAD dalam memori.  
Muat file DWF Anda menggunakan kelas `Image`, atur opsi PDF yang diinginkan, dan panggil `Save`. Operasi satu baris ini mempertahankan data vektor, lapisan, dan anotasi, menghasilkan PDF yang tampak persis seperti gambar sumber. Konversi ini menyimpan semua grafik vektor, teks, dan ketebalan garis, memastikan PDF cocok untuk pencetakan dan distribusi elektronik.

## Cara Mengekspor Gambar BMP dari File CAD?

`BmpOptions` mendefinisikan pengaturan untuk output BMP seperti resolusi, kedalaman warna, dan kompresi.  
Panggil metode `Image.Save` dengan `BmpOptions`, secara opsional sesuaikan lebar, tinggi, dan resolusi. ## Masalah Umum dan Solusinya

- **Font atau Jenis Garis Hilang**: Pastikan DWF mencakup semua sumber daya yang direferensikan atau sematkan mereka menggunakan `LoadOptions`.  
- **File Besar Melebihi Memori**: Gunakan `Image.Load(stream, LoadOptions)` dengan `LoadOptions.MemoryLimit` untuk menjaga penggunaan RAM tetap rendah.  
- **Distorsi Warna BMP**: Verifikasi `BmpOptions` `BitsPerPixel` diatur ke 24 atau 32 untuk output true‑color.

## Pertanyaan yang Sering Diajukan

**Q:** Bisakah saya mengonversi batch beberapa file DWF ke PDF?  
**A:** Ya – iterasikan folder, muat tiap file dengan `Image.Load`, dan panggil `Save` dengan opsi PDF di dalam loop.

**Q:** Apakah ekspor BMP mempertahankan petunjuk kedalaman 3‑D?  
**A:** Rasterizer menghasilkan bitmap datar, tetapi Anda dapat mengaktifkan shading dan pencahayaan melalui `RasterizationOptions` untuk kedalaman yang realistis.

**Q:** Apakah lisensi diperlukan untuk build pengembangan?  
**A:** Lisensi evaluasi sementara dapat digunakan untuk pengembangan; lisensi penuh wajib untuk penyebaran produksi.

**Q:** Platform apa yang didukung?  
**A:** Windows, Linux, dan macOS semuanya didukung saat menjalankan runtime .NET Core atau .NET 5+.

**Q:** Bagaimana Aspose.CAD menangani file DWF yang dilindungi kata sandi?  
**A:** Berikan kata sandi melalui `LoadOptions.Password` saat memuat file sumber.
