## Ad Alanlarını İçe Aktarma

`Image` sınıfı, bellekte bir CAD çizimini temsil eden temel sınıftır. `CadRasterizationOptions`, CAD çiziminin vektör çıktısı için nasıl rasterleştirileceğini tanımlar. `PdfOptions` sınıfı ise PDF dosyaları için çıktı ayarlarını belirtir.

``` 
using Aspose.CAD;
using Aspose.CAD.ImageOptions;
```

Bu ad alanları, CAD çizimlerini yükleme, rasterleştirme ve kaydetme işlevselliğinin çekirdeğini sağlar.

## Aspose.CAD kullanarak IGES'yi PDF'ye nasıl dönüştürülür?

`Image.Load` ile IGES dosyasını yükleyin ve hemen bir PDF rasterleştirme seçeneğiyle `Save` çağırın – bu, iki ifadeyle tam dönüşümü gerçekleştirir. Kütüphane vektör renderlamasını, yazı tipi gömmesini ve sayfa ölçeklendirmesini otomatik olarak yönetir, böylece orijinal IGES modelinin sadık bir PDF kopyasını elde edersiniz.

### Adım 1: Projenizi Kurun

Yeni bir .NET konsol veya sınıf‑kütüphane projesi oluşturun ya da dönüşüm özelliğini eklemek istediğiniz mevcut bir projeyi açın.

### Adım 2: Aspose.CAD Referansını Ekleyin

İndirilen Aspose.CAD DLL dosyasını proje referanslarınıza ekleyin. Visual Studio'da **References → Add Reference → Browse** üzerine sağ‑tıklayın ve DLL dosyasını seçin.

### Adım 3: Yolu Başlatın

IGES dosyanızın bulunduğu klasörü ve çıktı konumunu tanımlayın.

``` 
string sourceDir = @"C:\CAD\Source";
string outputDir = @"C:\CAD\Output";
string igesFile = Path.Combine(sourceDir, "sample.iges");
string pdfFile = Path.Combine(outputDir, "sample.pdf");
```

### Adım 4: CAD Görüntüsünü Yükleyin

`Image.Load` IGES dosyasını okur ve bellek içinde bir temsil oluşturur.

``` 
Image cadImage = Image.Load(igesFile);
```

`Image` sınıfı, Aspose.CAD'in herhangi bir CAD formatı için birincil giriş noktasıdır.

### Adım 5: Rasterleştirme Seçeneklerini Yapılandırın

`PdfOptions` (`CadRasterizationOptions` türevi), sayfa boyutu, çözünürlük ve vektör‑koruma bayraklarını ayarlamanıza olanak tanır.

``` 
PdfOptions pdfOptions = new PdfOptions
{
    VectorRasterizationOptions = new CadRasterizationOptions
    {
        PageWidth = 842,      // A4 width in points
        PageHeight = 595,     // A4 height in points
        Resolution = 300      // 300 DPI for high‑quality output
    }
};
```

`PdfOptions` sınıfı, CAD çiziminin nasıl rasterleştirileceğini ve PDF olarak kaydedileceğini tanımlar.

### Adım 6: PDF Olarak Kaydedin

Son olarak PDF dosyasını diske yazın.

``` 
cadImage.Save(pdfFile, pdfOptions);
```

Bu altı basit adımla, Aspose.CAD for .NET kullanarak **IGES'yi PDF'ye dönüştür** işlemini başarıyla tamamlamış oldunuz.

## Yaygın Tuzaklar ve İpuçları

- **Büyük dosyalar:** Daha ince detay gerekiyorsa `Resolution` değerini artırın; yüksek DPI daha fazla bellek tüketir.  
- **Eksik yazı tipleri:** IGES dosyasında kullanılan özel yazı tiplerinin sunucuda yüklü olduğundan emin olun; aksi takdirde yerine başka bir yazı tipi konulacaktır.  
- **Toplu dönüşüm:** Yükleme‑kaydetme mantığını bir `foreach` döngüsü içinde sararak birden fazla IGES dosyasını otomatik işleyin.
