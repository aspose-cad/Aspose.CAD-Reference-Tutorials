IGES को PDF में परिवर्तित करने में IGES न्यूट्रल‑एक्सचेंज फ़ाइल को पढ़ना, उसकी ज्यामितीय इकाइयों की व्याख्या करना, और उन्हें रास्टर या वेक्टर प्रतिनिधित्व में रेंडर करना शामिल है, जिसे फिर PDF दस्तावेज़ में एम्बेड किया जाता है। परिणामी PDF को किसी भी प्लेटफ़ॉर्म पर CAD सॉफ़्टवेयर की आवश्यकता के बिना देखा जा सकता है, जिससे मूल ड्रॉइंग की दृश्य लेआउट संरक्षित रहती है।

## Java में IGES कैसे लोड करें?
IGES फ़ाइल लोड करने के लिए, `Image` क्लास की स्टैटिक `load` मेथड को कॉल करें, जिसमें स्रोत फ़ाइल का पूर्ण पथ पास किया जाए। यह CAD ड्रॉइंग का इन‑मेमोरी प्रतिनिधित्व बनाता है, जिससे आप उसकी प्रॉपर्टीज़ की जाँच कर सकते हैं और बाद में इच्छित आउटपुट फ़ॉर्मेट में रास्टराइज़ कर सकते हैं।

```text
```java
import com.aspose.cad.Image;
import com.aspose.cad.Image;

import com.aspose.cad.imageoptions.CadRasterizationOptions;
import com.aspose.cad.imageoptions.PdfOptions;
```
```

> **Pro tip:** कभी‑कभी जेनरेटेड सैंपल्स में दिखाई देने वाली डुप्लिकेट `import com.aspose.cad.Image;` लाइन हानिरहित है लेकिन साफ़ फ़ाइल के लिए इसे हटाया जा सकता है।

## IGES से कस्टम PDF पेज कैसे बनाएं?
कस्टम‑साइज़ PDF पेज बनाने के लिए रास्टराइज़ेशन विकल्पों को परिभाषित करना आवश्यक है जो पेज की चौड़ाई, ऊँचाई, DPI, और बैकग्राउंड रंग निर्दिष्ट करते हैं। इन सेटिंग्स को समायोजित करके आप A4 जैसे मानक कागज़ आकार से मेल कर सकते हैं या पोस्टर के लिए विशेष आयाम बना सकते हैं, जिससे रेंडर किया गया ड्रॉइंग लक्ष्य लेआउट में सटीक रूप से फिट हो।

`CadRasterizationOptions` वह सेटिंग्स कंटेनर है जो Aspose.CAD को बताता है कि CAD ड्रॉइंग को कैसे रास्टराइज़ किया जाए—पेज की चौड़ाई, ऊँचाई, DPI, और रेंडरिंग मोड।

```text
```java
String sourceFilePath = dataDir + "figa2.igs";
Image igesImage = Image.load(sourceFilePath);
```
```

उदाहरण में हमने दोनों `PageHeight` और `PageWidth` को **1000 pixels** पर सेट किया है, लेकिन आप इन मानों को अपनी दस्तावेज़ीकरण मानकों के अनुसार किसी भी आकार में बदल सकते हैं, जैसे A4 (595 × 842 pt) या कस्टम पोस्टर आयाम।

## परिणामी PDF कैसे सहेजें?
`PdfOptions` PDF‑विशिष्ट पैरामीटर जैसे कम्प्रेशन और वेक्टर रास्टराइज़ेशन सेटिंग्स को परिभाषित करता है। `CadRasterizationOptions` को कॉन्फ़िगर करने के बाद, उन्हें `PdfOptions` इंस्टेंस को असाइन करें और `Image` ऑब्जेक्ट पर `save` मेथड को कॉल करें, जिसमें आउटपुट फ़ाइल पाथ और विकल्प ऑब्जेक्ट प्रदान किया जाए।

`save` मेथड इन‑मेमोरी इमेज को चुने हुए फ़ाइल फ़ॉर्मेट में लिखता है, सभी पूर्वनिर्धारित रास्टराइज़ेशन विकल्पों को लागू करता है।

```text
```java
String outPath = dataDir + "meshes.pdf";
PdfOptions pdf = new PdfOptions();
CadRasterizationOptions vectorOptions = new CadRasterizationOptions();
vectorOptions.setPageHeight(1000);
vectorOptions.setPageWidth(1000);
pdf.setVectorRasterizationOptions(vectorOptions);
```
```

इस कॉल के बाद, एक पूरी तरह रेंडर किया गया PDF `dataDir` फ़ोल्डर में दिखाई देगा, जो वितरण या आगे की प्रोसेसिंग के लिए तैयार है।
