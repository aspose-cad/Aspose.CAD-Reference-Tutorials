# Aspose CAD वॉटरमार्क को ड्रॉइंग्स में कैसे जोड़ें

## परिचय

एक **aspose cad watermark** जोड़ने से आप बौद्धिक संपदा की सुरक्षा कर सकते हैं और प्रत्येक साझा की गई ड्रॉइंग पर ब्रांड लगा सकते हैं। Aspose.CAD for .NET के साथ आप DWG, DXF या अन्य समर्थित CAD फ़ॉर्मैट्स में सीधे वॉटरमार्क एम्बेड कर सकते हैं, बिना मूल डिज़ाइन सॉफ़्टवेयर की आवश्यकता के। इस ट्यूटोरियल में आप देखेंगे कि वॉटरमार्क क्यों महत्वपूर्ण हैं, कौनसे फ़ॉर्मैट समर्थित हैं, और चरण‑दर‑चरण उन्हें कैसे लागू करें।

## त्वरित उत्तर
- **मुझे कौनसी लाइब्रेरी चाहिए?** Aspose.CAD for .NET (आधिकारिक साइट से डाउनलोड करें)।  
- **मैं किन फ़ाइल प्रकारों पर वॉटरमार्क लगा सकता हूँ?** 30 से अधिक CAD/BIM फ़ॉर्मैट्स, जिसमें DWG, DXF, DWF, और DGN शामिल हैं।  
- **क्या मैं परिणाम को PDF के रूप में निर्यात कर सकता हूँ?** हाँ – वही API आपको एक लाइन में वॉटरमार्क वाली ड्रॉइंग को PDF में सहेजने की सुविधा देती है।  
- **क्या विकास के लिए लाइसेंस चाहिए?** परीक्षण के लिए एक मुफ्त ट्रायल काम करता है; उत्पादन के लिए व्यावसायिक लाइसेंस आवश्यक है।  
- **क्या कोड .NET 6 के साथ संगत है?** बिल्कुल – Aspose.CAD .NET Framework 4.5+, .NET Core 3.1+, .NET 5+ और .NET 6+ को सपोर्ट करता है।

## Aspose CAD वॉटरमार्क क्या है?
एक **Aspose CAD watermark** एक टेक्स्ट या MTEXT एंटिटी है जिसे Aspose.CAD CAD ड्रॉइंग के मॉडल स्पेस में डालता है, जो एक अर्ध‑पारदर्शी ओवरले के रूप में प्रदर्शित होता है और फ़ाइल के साथ चलता है। यह ड्रॉइंग की सुरक्षा करता है जबकि मानक CAD व्यूअर्स में संपादन योग्य रहता है।

## वॉटरमार्किंग के लिए Aspose.CAD का उपयोग क्यों करें?
Aspose.CAD **30+** CAD और BIM फ़ॉर्मैट्स को प्रोसेस कर सकता है और **1,000 पेज** तक की फ़ाइलों को पूरी दस्तावेज़ को मेमोरी में लोड किए बिना संभाल सकता है। यह मापनीय क्षमता आपको बड़े इंजीनियरिंग अभिलेखों को बैच‑प्रोसेस करने की अनुमति देती है, जिससे सर्वर मेमोरी उपयोग **70 %** तक घट जाता है, साधारण फ़ाइल‑दर‑फ़ाइल लोडिंग की तुलना में।

- वह फ़ोल्डर जिसमें वह CAD ड्रॉइंग्स हैं जिन्हें आप वॉटरमार्क करना चाहते हैं।  
- एक वैध Aspose लाइसेंस (ट्रायल रन के लिए वैकल्पिक)।

## CAD ड्रॉइंग में वॉटरमार्क कैसे जोड़ें?

आप बस CAD फ़ाइल को लोड करते हैं, एक वॉटरमार्क एंटिटी (MTEXT या Text) बनाते हैं, उसे मॉडल स्पेस में जोड़ते हैं, और फिर इच्छित फ़ॉर्मैट (जैसे PDF) में इमेज सहेजते हैं। यह तरीका किसी भी समर्थित CAD फ़ॉर्मैट पर काम करता है और बैच प्रोसेसिंग के लिए स्क्रिप्ट किया जा सकता है।

## नेमस्पेस आयात करें

`using Aspose.CAD;`  
`using Aspose.CAD.ImageOptions;`  
`using Aspose.CAD.FileFormats.Cad;`  

## चरण 1: CAD ड्रॉइंग लोड करें

`CadImage` क्लास एक CAD ड्रॉइंग को मेमोरी में लोड किए गए रूप में दर्शाता है और उसकी एंटिटीज़ तक पहुँच प्रदान करता है।  
```markdown
```csharp
using Aspose.CAD.FileFormats.Cad;
using Aspose.CAD.FileFormats.Cad.CadObjects;
using Aspose.CAD.ImageOptions;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```
```

## चरण 2: वॉटरमार्क को MTEXT के रूप में जोड़ें

`CadMText` एक एंटिटी है जो फ़ॉर्मैटिंग के साथ मल्टी‑लाइन टेक्स्ट संग्रहीत करती है, जो वॉटरमार्क संदेशों के लिए उपयुक्त है।  
```markdown
```csharp
// The path to the documents directory.
string MyDir = "Your Document Directory";
using (CadImage cadImage = (CadImage)Image.Load(MyDir + "Drawing11.dwg")) {
```
```

## चरण 3: या वॉटरमार्क को साधारण टेक्स्ट के रूप में जोड़ें

`CadText` एक सिंगल‑लाइन टेक्स्ट एंटिटी को दर्शाता है जिसे ड्रॉइंग के मॉडल स्पेस में रखा जा सकता है।  
```markdown
```csharp
// Add new MTEXT
CadMText watermark = new CadMText();
watermark.Text = "Watermark message";
watermark.InitialTextHeight = 40;
watermark.InsertionPoint = new Cad3DPoint(300, 40);
watermark.LayerName = "0";
cadImage.BlockEntities["*Model_Space"].AddEntity(watermark);
```
```

## चरण 4: PDF में निर्यात करें

`CadRasterizationOptions` निर्धारित करता है कि CAD ड्रॉइंग कैसे रास्टराइज़ की जाती है, जबकि `PdfOptions` PDF आउटपुट सेटिंग्स को निर्दिष्ट करता है।  
```markdown
```csharp
// Alternatively, add a simpler entity like Text
CadText text = new CadText();
text.DefaultValue = "Watermark text";
text.TextHeight = 40;
text.FirstAlignment = new Cad3DPoint(300, 40);
text.LayerName = "0";
cadImage.BlockEntities["*Model_Space"].AddEntity(text);
```
```

इन चरणों को अपनी संग्रह में प्रत्येक ड्रॉइंग के लिए दोहराएँ, और आप वितरण के लिए तैयार पेशेवर, वॉटरमार्क वाली CAD फ़ाइलें उत्पन्न करेंगे।

## सामान्य समस्याएँ और समाधान

- **एक्सपोर्ट के बाद वॉटरमार्क दिखाई नहीं देता** – सुनिश्चित करें कि MTEXT या Text एंटिटी की `Opacity` प्रॉपर्टी 0.3 से 0.7 के बीच सेट हो; इस रेंज से बाहर के मान पूरी तरह अपारदर्शी या अदृश्य हो सकते हैं।  
- **बड़ी फ़ाइलों से मेमोरी स्पाइक** – `Image.Load` को `LoadOptions` पैरामीटर के साथ उपयोग करें ताकि स्ट्रीमिंग सक्षम हो, जिससे मेमोरी उपयोग कम रहता है।  
- **फ़ॉन्ट रेंडरिंग में त्रुटि** – सर्वर पर वही TrueType फ़ॉन्ट इंस्टॉल करें जो ड्रॉइंग बनाते समय उपयोग किए गए थे, या `MText.Font` के माध्यम से फ़ॉलबैक फ़ॉन्ट एम्बेड करें।
