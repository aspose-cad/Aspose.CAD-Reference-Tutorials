# IGES को PDF में बदलें Aspose.CAD के साथ

## परिचय

कंप्यूटर‑सहायित डिजाइन की तेज़ गति वाली दुनिया में, **convert IGES to PDF** एक नियमित कार्य है जिसे इंजीनियर और आर्किटेक्ट रोज़ाना करते हैं। चाहे आपको क्लाइंट रिव्यू के लिए प्रिंटेबल दस्तावेज़ चाहिए या संस्करण नियंत्रण के लिए हल्का अभिलेख चाहिए, IGES फ़ाइलों को PDF में निर्यात करने से मूल ज्यामिति संरक्षित रहती है और फ़ाइल सार्वभौमिक रूप से सुलभ हो जाती है। यह ट्यूटोरियल आपको Aspose.CAD for .NET का उपयोग करके IGES को PDF में बदलने के सटीक चरणों के माध्यम से ले जाता है, ताकि आप किसी भी .NET एप्लिकेशन में इस प्रक्रिया को स्वचालित कर सकें।

## “convert IGES to PDF” क्या है?
*Converting IGES to PDF* का मतलब है एक तटस्थ CAD एक्सचेंज फ़ाइल (IGES) को पोर्टेबल डॉक्यूमेंट फ़ॉर्मेट (PDF) के रूप में रेंडर करना, जिसे किसी भी डिवाइस पर CAD सॉफ़्टवेयर के बिना खोला जा सकता है। परिवर्तन वेक्टर ज्यामिति, लेयर्स, और एनोटेशन को संरक्षित रखता है जबकि उन्हें एक स्थिर‑लेआउट दस्तावेज़ में फ्लैटन करता है।

## नेमस्पेस इम्पोर्ट करें
`Image` क्लास मेमोरी में CAD ड्रॉइंग का प्रतिनिधित्व करने वाली मुख्य क्लास है। `CadRasterizationOptions` निर्धारित करता है कि CAD ड्रॉइंग को वेक्टर आउटपुट के लिए कैसे रास्टर किया जाए। `PdfOptions` क्लास PDF फ़ाइलों के आउटपुट सेटिंग्स को निर्दिष्ट करती है।

``` 
using Aspose.CAD;
using Aspose.CAD.ImageOptions;
```

ये नेमस्पेस CAD ड्रॉइंग को लोड, रास्टर और सहेजने के लिए मुख्य कार्यक्षमता प्रदान करते हैं।

## Aspose.CAD का उपयोग करके IGES को PDF में कैसे बदलें?
`Image.Load` के साथ IGES फ़ाइल लोड करें और तुरंत `Save` को PDF रास्टराइज़ेशन विकल्प के साथ कॉल करें – यह दो कथनों में पूर्ण परिवर्तन है। लाइब्रेरी स्वचालित रूप से वेक्टर रेंडरिंग, फ़ॉन्ट एम्बेडिंग, और पेज स्केलिंग को संभालती है, इसलिए आपको मूल IGES मॉडल की एक सटीक PDF प्रतिलिपि मिलती है।

### चरण 1: अपना प्रोजेक्ट सेट अप करें
एक नया .NET कंसोल या क्लास‑लाइब्रेरी प्रोजेक्ट बनाएं, या मौजूदा प्रोजेक्ट खोलें जहाँ आप परिवर्तन सुविधा जोड़ना चाहते हैं।

### चरण 2: Aspose.CAD रेफ़रेंस जोड़ें
डाउनलोड की गई Aspose.CAD DLL को अपने प्रोजेक्ट रेफ़रेंसेज़ में जोड़ें। Visual Studio में, **References → Add Reference → Browse** पर राइट‑क्लिक करें और DLL चुनें।

### चरण 3: पाथ को इनिशियलाइज़ करें
उस फ़ोल्डर को परिभाषित करें जिसमें आपका IGES फ़ाइल है और आउटपुट स्थान।

``` 
string sourceDir = @"C:\CAD\Source";
string outputDir = @"C:\CAD\Output";
string igesFile = Path.Combine(sourceDir, "sample.iges");
string pdfFile = Path.Combine(outputDir, "sample.pdf");
```

### चरण 4: CAD इमेज लोड करें
`Image.Load` IGES फ़ाइल को पढ़ता है और मेमोरी में एक प्रतिनिधित्व बनाता है।

``` 
Image cadImage = Image.Load(igesFile);
```

`Image` क्लास Aspose.CAD का किसी भी CAD फ़ॉर्मेट के लिए मुख्य एंट्री पॉइंट है।

### चरण 5: रास्टराइज़ेशन विकल्प कॉन्फ़िगर करें
`PdfOptions` (`CadRasterizationOptions` से व्युत्पन्न) आपको पेज आकार, रिज़ॉल्यूशन, और वेक्टर‑सुरक्षित फ़्लैग सेट करने की अनुमति देता है।

``` 
PdfOptions pdfOptions = new PdfOptions
{
    VectorRasterizationOptions = new CadRasterizationOptions
    {
        PageWidth = 842,      // A4 width in points
        PageHeight = 595,     // A4 height in points
        Resolution = 300      // 300 DPI for high‑quality output
    }
};
```

`PdfOptions` क्लास निर्धारित करती है कि CAD ड्रॉइंग को कैसे रास्टर किया जाए और PDF के रूप में सहेजा जाए।

### चरण 6: PDF के रूप में सहेजें
अंत में, PDF फ़ाइल को डिस्क पर लिखें।

``` 
cadImage.Save(pdfFile, pdfOptions);
```

इन छह सरल चरणों के साथ, आपने सफलतापूर्वक Aspose.CAD for .NET का उपयोग करके **convert iges to pdf** किया है।

## सामान्य समस्याएँ और सुझाव
- **बड़ी फ़ाइलें:** केवल तभी `Resolution` बढ़ाएँ जब आपको अधिक विस्तृत विवरण चाहिए; उच्च DPI अधिक मेमोरी खपत करता है।  
- **फ़ॉन्ट गायब:** सुनिश्चित करें कि IGES फ़ाइल में उपयोग किए गए किसी भी कस्टम फ़ॉन्ट सर्वर पर स्थापित हों; अन्यथा, उन्हें प्रतिस्थापित किया जाएगा।  
- **बैच परिवर्तन:** `load‑save` लॉजिक को `foreach` लूप में रैप करें ताकि कई IGES फ़ाइलों को स्वचालित रूप से प्रोसेस किया जा सके।
