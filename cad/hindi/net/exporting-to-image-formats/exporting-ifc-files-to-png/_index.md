# CAD को PNG में निर्यात कैसे करें – Aspose.CAD के साथ IFC फ़ाइलों का निर्यात

## परिचय

यदि आपको **how to export cad to png** की आवश्यकता है, तो Aspose.CAD for .NET एक विश्वसनीय, कोड‑रहित तरीका प्रदान करता है जिससे IFC (Industry Foundation Classes) मॉडल को स्पष्ट PNG रास्टर इमेज में बदला जा सकता है। इस ट्यूटोरियल में हम पूरे वर्कफ़्लो को चरण‑दर‑चरण देखेंगे—लाइब्रेरी को इंस्टॉल करने से लेकर अंतिम PNG को सेव करने तक—ताकि आप इस रूपांतरण को किसी भी .NET एप्लिकेशन में आत्मविश्वास के साथ एकीकृत कर सकें।

## त्वरित उत्तर
- **कौन सी लाइब्रेरी रूपांतरण को संभालती है?** Aspose.CAD for .NET.
- **समर्थित स्रोत फ़ॉर्मेट?** IFC (Industry Foundation Classes) फ़ाइलें.
- **लक्ष्य इमेज फ़ॉर्मेट?** PNG, आकार और रिज़ॉल्यूशन पर पूर्ण नियंत्रण के साथ.
- **न्यूनतम .NET संस्करण?** .NET Framework 4.5+ या .NET Core 3.1+.
- **लाइसेंस आवश्यकता?** उत्पादन उपयोग के लिए एक वैध Aspose.CAD लाइसेंस।

## “how to export cad to png” क्या है?

यह वाक्यांश CAD‑आधारित फ़ाइल फ़ॉर्मेट, जैसे IFC, को पोर्टेबल नेटवर्क ग्राफ़िक्स (PNG) रास्टर इमेज में बदलने की प्रक्रिया को दर्शाता है। यह रूपांतरण वेब पेज, दस्तावेज़ या रिपोर्ट में CAD विज़ुअल को आसानी से देखने, साझा करने और एम्बेड करने की सुविधा देता है, एक हल्का, व्यापक रूप से समर्थित फ़ॉर्मेट प्रदान करता है जो दृश्य सटीकता को बनाए रखता है बिना विशेष CAD व्यूअर्स की आवश्यकता के।

## इस रूपांतरण के लिए Aspose.CAD क्यों उपयोग करें?

Aspose.CAD **50+ CAD और BIM फ़ॉर्मेट** को सपोर्ट करता है और पूरे फ़ाइल को मेमोरी में लोड किए बिना सैकड़ों‑पृष्ठों वाले IFC मॉडल को प्रोसेस कर सकता है। यह मानक सर्वर हार्डवेयर पर तेज़, मेमोरी‑कुशल रूपांतरण प्रदान करता है, लेयर्स, लाइन वेट और रंग मैपिंग को स्वचालित रूप से संभालते हुए आउटपुट गुणवत्ता और आकार के लिए विस्तृत कॉन्फ़िगरेशन विकल्प देता है।

### 2. दस्तावेज़ डायरेक्टरी

## नेमस्पेस इम्पोर्ट करें
अब जब पूर्वापेक्षाएँ तैयार हैं, अपने .NET प्रोजेक्ट में Aspose.CAD के साथ काम करने के लिए आवश्यक नेमस्पेस इम्पोर्ट करें।

```csharp
using Aspose.CAD.ImageOptions;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using Aspose.CAD.FileFormats.Ifc;
```

## CAD को PNG में कैसे निर्यात करें?

`IfcImage` एक IFC CAD इमेज को दर्शाता है जिसे PNG जैसे रास्टर फ़ॉर्मेट में रास्टराइज़ किया जा सकता है। अपने IFC फ़ाइल को `new IfcImage("source.ifc")` से लोड करें, `RasterizationOptions` के माध्यम से रास्टराइज़ेशन कॉन्फ़िगर करें, `PngOptions` के साथ PNG‑विशिष्ट सेटिंग्स सेट करें, और अंत में `Save(outputPath, pngOptions)` को कॉल करें। यह एंड‑टू‑एंड फ्लो CAD मॉडल को कुछ ही कोड लाइनों में हाई‑रेज़ॉल्यूशन PNG में बदल देता है, लेयर्स, रंग और लाइन वेट को स्वचालित रूप से संभालते हुए।

## चरण 1: IFC फ़ाइल लोड करें
`IfcImage` क्लास एक IFC मॉडल को लोड करती है और उसे रास्टराइज़ेशन के लिए तैयार करती है।

```csharp
string MyDir = "Your Document Directory";
string sourceFilePath = MyDir + "example.ifc";
using (IfcImage cadImage = (IfcImage)Image.Load(sourceFilePath))
{
```

इस चरण में हम Aspose.CAD `IfcImage` ऑब्जेक्ट को इनिशियलाइज़ करते हैं और उसमें IFC फ़ाइल लोड करते हैं।

## चरण 2: रास्टराइज़ेशन विकल्प सेट करें
`RasterizationOptions` क्लास यह निर्धारित करती है कि वेक्टर डेटा को रास्टर इमेज में कैसे बदला जाए, जिसमें पेज की चौड़ाई, ऊँचाई और बैकग्राउंड रंग शामिल हैं।

```csharp
    CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
   
    rasterizationOptions.PageWidth = 100;
    rasterizationOptions.PageHeight = 100;
```

PNG आउटपुट के लिए पेज की चौड़ाई और ऊँचाई कॉन्फ़िगर करने हेतु रास्टराइज़ेशन विकल्प निर्धारित करें।

## चरण 3: PNG विकल्प सेट करें
`PngOptions` क्लास PNG आउटपुट के विशिष्ट सेटिंग्स रखती है, जैसे कम्प्रेशन लेवल और कलर डेप्थ।

```csharp
    PngOptions pngOptions = new PngOptions();
    pngOptions.VectorRasterizationOptions = rasterizationOptions;
```

PNG विकल्प बनाएं और पहले परिभाषित रास्टराइज़ेशन विकल्पों को उससे जोड़ें।

## चरण 4: आउटपुट पाथ निर्दिष्ट करें
आउटपुट पाथ निर्धारित करता है कि उत्पन्न PNG फ़ाइल कहाँ सेव होगी।

```csharp
    // Set output path as well
    string outPath = sourceFilePath + ".png";
    cadImage.Save(outPath, pngOptions);
}
```

PNG फ़ाइल के लिए आउटपुट पाथ निर्धारित करें, यह सुनिश्चित करते हुए कि इसका नाम स्रोत फ़ाइल के समान हो और एक्सटेंशन ".png" हो। अंत में, परिवर्तित इमेज को सेव करें।

## सामान्य समस्याएँ और समाधान
- **फ़ॉन्ट या लाइन स्टाइल गायब:** सुनिश्चित करें कि स्रोत IFC सभी आवश्यक संसाधनों को संदर्भित करता है; Aspose.CAD संभव होने पर गायब एसेट्स को एम्बेड करता है।
- **बड़ी फ़ाइलें मेमोरी स्पाइक का कारण बनती हैं:** मेमोरी उपयोग को सीमित करने के लिए `RasterizationOptions` पर `MemoryLimit` प्रॉपर्टी का उपयोग करें।
- **गलत रंग:** पुष्टि करें कि स्रोत IFC रंग परिभाषाएँ IFC स्कीमा के अनुरूप हैं; Aspose.CAD मानक रंग मैपिंग का सम्मान करता है।
