# Aspose.CAD का उपयोग करके CAD को BMP फ़ॉर्मेट में निर्यात कैसे करें

## परिचय

यदि आप **Aspose.CAD का उपयोग कैसे करें** को लेकर CAD ड्रॉइंग को BMP इमेज में बदलना चाहते हैं, तो आप सही जगह पर आए हैं। इस ट्यूटोरियल में हम पूरे वर्कफ़्लो को चरणबद्ध रूप से देखेंगे—लाइब्रेरी को इंस्टॉल करने से लेकर 3‑D CAD फ़ाइल को उच्च‑गुणवत्ता वाले BMP बिटमैप के रूप में निर्यात करने तक। अंत तक आप पूरी **cad file format conversion** प्रक्रिया को समझ जाएंगे और इसे अपने .NET एप्लिकेशन्स में एकीकृत करने के लिए तैयार हो जाएंगे।

## त्वरित उत्तर

- **कौन सी लाइब्रेरी आवश्यक है?** Aspose.CAD for .NET (download from the official site).  
- **कौन से CAD फ़ॉर्मेट निर्यात किए जा सकते हैं?** Over 30 formats, including DWG, DWF, and DXF.  
- **क्या मैं 3‑D मॉडल निर्यात कर सकता हूँ?** Yes, Aspose.CAD renders 3‑D geometry to BMP, PNG, JPEG, and more.  
- **परीक्षण के लिए क्या मुझे लाइसेंस चाहिए?** A free temporary license is available for evaluation.  
- **.NET संस्करण कौन से समर्थित हैं?** .NET Framework 4.5+, .NET Core 2.0+, .NET 5/6/7.

## Aspose.CAD क्या है?

**Aspose.CAD** एक .NET API है जो डेवलपर्स को किसी भी मूल CAD सॉफ़्टवेयर की आवश्यकता के बिना CAD ड्रॉइंग को लोड, संशोधित और परिवर्तित करने में सक्षम बनाता है। यह 30+ इनपुट फ़ॉर्मेट का समर्थन करता है और उन्हें BMP, PNG, और JPEG जैसे रास्टर इमेज में रेंडर कर सकता है।

## CAD को BMP में निर्यात क्यों करें?

Aspose.CAD **BMP को 100‑पृष्ठीय ड्रॉइंग्स के लिए अधिकतम 150 Mbps की गति से निर्यात कर सकता है**, जिससे वेक्टर की सटीकता बनी रहती है जबकि एक ऐसा रास्टर फ़ॉर्मेट प्रदान करता है जो लेगेसी सिस्टम्स द्वारा सार्वभौमिक रूप से समर्थित है। BMP फ़ाइलें अनकम्प्रेस्ड होती हैं, जिससे वे उन डाउनस्ट्रीम इमेज प्रोसेसिंग पाइपलाइनों के लिए आदर्श बनती हैं जिन्हें पिक्सेल‑परफेक्ट डेटा की आवश्यकता होती है।

## Aspose.CAD का उपयोग करके CAD को BMP में कैसे निर्यात करें?

`Image.Load` के साथ अपना CAD फ़ाइल लोड करें, रास्टराइज़ेशन विकल्प कॉन्फ़िगर करें, और `Save` को कॉल करके BMP फ़ाइल लिखें। पूरी रूपांतरण केवल तीन कोड लाइनों में किया जाता है, और Aspose.CAD स्वचालित रूप से वेक्टर‑से‑रास्टर रूपांतरण, लाइन‑वेट स्केलिंग, और बैकग्राउंड कलर प्रबंधन को संभालता है।

## नेमस्पेस आयात करें

अपने .NET प्रोजेक्ट में, आवश्यक नेमस्पेस आयात करना सुनिश्चित करें। `using` स्टेटमेंट्स आवश्यक .NET और Aspose.CAD नेमस्पेस को स्कोप में लाते हैं।  
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;
using Aspose.CAD;
using Aspose.CAD.ImageOptions;
```

## चरण 1: CAD इमेज लोड करें

सबसे पहले अपने प्रोजेक्ट में CAD इमेज लोड करें। **“Your Document Directory”** को वास्तविक डायरेक्टरी पाथ से बदलें। `Image` मेमोरी में लोड किए गए CAD ड्रॉइंग को दर्शाता है और रेंडरिंग व रूपांतरण के लिए मेथड्स प्रदान करता है।  
```csharp
string MyDir = "Your Document Directory";
string inputFile = MyDir + "18-12-11 9644 - site.dwf";

using (Image image = Image.Load(inputFile))
{
    // Your code for loading the image goes here
}
```

## चरण 2: BMP निर्यात विकल्प कॉन्फ़िगर करें

BMP निर्यात विकल्प सेट करें, जिसमें CAD फ़ाइलों के लिए वेक्टर रास्टराइज़ेशन विकल्प शामिल हैं। `BmpOptions` BMP आउटपुट सेटिंग्स को निर्दिष्ट करता है, जबकि `CadRasterizationOptions` नियंत्रित करता है कि CAD वेक्टर कैसे रास्टराइज़ किए जाएँ।  
```csharp
BmpOptions bmpOptions = new BmpOptions();
var dwfRasterizationOptions = new CadRasterizationOptions();
bmpOptions.VectorRasterizationOptions = dwfRasterizationOptions;

dwfRasterizationOptions.PageHeight = 500;
dwfRasterizationOptions.PageWidth = 500;
```

## चरण 3: BMP में निर्यात करें

निर्यात प्रक्रिया को निष्पादित करें, BMP फ़ाइल के आउटपुट पाथ को निर्दिष्ट करते हुए। `Save` प्रदान किए गए निर्यात विकल्पों का उपयोग करके इमेज को निर्दिष्ट फ़ाइल में लिखता है।  
```csharp
string outPath = MyDir + "18-12-11 9644 - site.bmp";
image.Save(outPath, bmpOptions);
```

## सामान्य समस्याएँ और समाधान

- **Blank BMP output** – सुनिश्चित करें कि `VectorRasterizationOptions` ऑब्जेक्ट में `PageWidth` और `PageHeight` शून्य नहीं हैं।  
- **Incorrect colours** – `BmpOptions` में `BackgroundColor` को अपनी इच्छित कैनवास रंग के अनुसार सेट करें।  
- **Large files cause memory pressure** – CAD फ़ाइल को स्ट्रीमिंग मोड में प्रोसेस करने के लिए `LoadOptions` के साथ `LoadMode = LoadMode.Stream` का उपयोग करें।
