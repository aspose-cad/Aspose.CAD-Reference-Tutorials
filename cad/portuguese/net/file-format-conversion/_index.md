## Como Converter DWF para PDF com Aspose.CAD?
`Image` é a classe principal do Aspose.CAD que representa um documento CAD na memória.  
Carregue seu arquivo DWF usando a classe `Image`, defina as opções de PDF desejadas e chame `Save`. Esta operação de uma única linha preserva dados vetoriais, camadas e anotações, entregando um PDF que parece exatamente o desenho original. A conversão mantém todos os gráficos vetoriais, texto e espessuras de linha, garantindo que o PDF seja adequado para impressão e distribuição eletrônica.

## Como Exportar Imagens BMP de Arquivos CAD?
`BmpOptions` define as configurações para saída BMP, como resolução, profundidade de cor e compressão.  
Chame o método `Image.Save` com `BmpOptions`, ajustando opcionalmente largura, altura e resolução. A biblioteca rasteriza o modelo 3‑D em um bitmap, oferecendo controle total sobre a qualidade da imagem e profundidade de cor. Você também pode especificar DPI e escolher entre modos de cor de 24‑bits ou 32‑bits para atender aos requisitos do seu projeto.

## Problemas Comuns e Soluções
- **Fontes ou Tipos de Linha Ausentes**: Certifique‑se de que o DWF inclua todos os recursos referenciados ou incorpore‑os usando `LoadOptions`.  
- **Arquivos Grandes Excedem a Memória**: Use `Image.Load(stream, LoadOptions)` com `LoadOptions.MemoryLimit` para manter o uso de RAM baixo.  
- **Distorção de Cor BMP**: Verifique se `BmpOptions` `BitsPerPixel` está definido como 24 ou 32 para saída em cores verdadeiras.

## Perguntas Frequentes

**Q: Posso converter em lote vários arquivos DWF para PDF?**  
A: Sim – itere sobre uma pasta, carregue cada arquivo com `Image.Load` e chame `Save` com as opções de PDF dentro do loop.

**Q: A exportação BMP preserva pistas de profundidade 3‑D?**  
A: O rasterizador cria um bitmap plano, mas você pode habilitar sombreamento e iluminação via `RasterizationOptions` para profundidade realista.

**Q: É necessária uma licença para compilações de desenvolvimento?**  
A: Uma licença de avaliação temporária funciona para desenvolvimento; uma licença completa é obrigatória para implantações em produção.

**Q: Quais plataformas são suportadas?**  
A: Windows, Linux e macOS são todos suportados ao executar .NET Core ou runtimes .NET 5+.

**Q: Como o Aspose.CAD lida com arquivos DWF protegidos por senha?**  
A: Forneça a senha através de `LoadOptions.Password` ao carregar o arquivo fonte.
