## 介绍

## Aspose.CAD for .NET 是什么？
Aspose.CAD for .NET 是一个 .NET 库，可实现以编程方式进行 **CAD 文件格式转换**，无需原生 CAD 软件。它支持超过 30 种输入和输出格式，以内存高效的流处理数百页的文件，并保证像素级完美渲染。

## 如何使用 Aspose.CAD 将 DWF 转换为 PDF？

`Image` 是 Aspose.CAD 的核心类，表示内存中的 CAD 文档。  
使用 `Image` 类加载您的 DWF 文件，设置所需的 PDF 选项，然后调用 `Save`。此一行代码即可保留矢量数据、图层和注释，生成与源图纸完全相同的 PDF。转换会保留所有矢量图形、文本和线宽，确保 PDF 适合打印和电子分发。

## 如何从 CAD 文件导出 BMP 图像？

`BmpOptions` 定义了 BMP 输出的设置，例如分辨率、色深和压缩方式。  
使用 `BmpOptions` 调用 `Image.Save` 方法，可选地调整宽度、高度和分辨率。该库将 3‑D 模型光栅化为位图，让您完全控制图像质量和色深。您还可以指定 DPI，并在 24 位或 32 位颜色模式之间选择，以匹配项目需求。

## 常见问题与解决方案

- **缺少字体或线型**：确保 DWF 包含所有引用的资源，或使用 `LoadOptions` 将其嵌入。  
- **大文件超出内存**：使用 `Image.Load(stream, LoadOptions)` 并设置 `LoadOptions.MemoryLimit` 以降低 RAM 使用。  
- **BMP 颜色失真**：确认 `BmpOptions` 的 `BitsPerPixel` 设置为 24 或 32，以获得真彩色输出。

## 常见问答

**问：我可以批量将多个 DWF 文件转换为 PDF 吗？**  
答：可以——遍历文件夹，使用 `Image.Load` 加载每个文件，并在循环中使用 PDF 选项调用 `Save`。

**问：BMP 导出是否保留 3‑D 深度线索？**  
答：光栅化器生成的是平面位图，但您可以通过 `RasterizationOptions` 启用阴影和光照，以获得逼真的深度效果。

**问：开发构建是否需要许可证？**  
答：临时评估许可证可用于开发；正式生产部署必须使用完整许可证。

**问：支持哪些平台？**  
答：在运行 .NET Core 或 .NET 5+ 运行时的情况下，Windows、Linux 和 macOS 均受支持。

**问：Aspose.CAD 如何处理受密码保护的 DWF 文件？**  
答：在加载源文件时，通过 `LoadOptions.Password` 提供密码。
