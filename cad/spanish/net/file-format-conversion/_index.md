## Cómo Convertir DWF a PDF con Aspose.CAD?
`Image` es la clase principal de Aspose.CAD que representa un documento CAD en memoria.  
Carga tu archivo DWF usando la clase `Image`, establece las opciones de PDF deseadas y llama a `Save`. Esta operación de una sola línea preserva los datos vectoriales, capas y anotaciones, entregando un PDF que se ve exactamente como el dibujo original. La conversión conserva todos los gráficos vectoriales, texto y grosores de línea, asegurando que el PDF sea adecuado para impresión y distribución electrónica.

## Cómo Exportar Imágenes BMP desde Archivos CAD?
`BmpOptions` define las configuraciones para la salida BMP, como resolución, profundidad de color y compresión.  
Llama al método `Image.Save` con `BmpOptions`, ajustando opcionalmente el ancho, alto y resolución. La biblioteca rasteriza el modelo 3‑D en un bitmap, dándote control total sobre la calidad de la imagen y la profundidad de color. También puedes especificar DPI y elegir entre modos de color de 24‑bits o 32‑bits para adaptarse a los requisitos de tu proyecto.

## Problemas Comunes y Soluciones
- **Fuentes o tipos de línea faltantes**: Asegúrate de que el DWF incluya todos los recursos referenciados o incrústalos usando `LoadOptions`.  
- **Archivos grandes exceden la memoria**: Usa `Image.Load(stream, LoadOptions)` con `LoadOptions.MemoryLimit` para mantener bajo el uso de RAM.  
- **Distorsión de color BMP**: Verifica que `BmpOptions` `BitsPerPixel` esté configurado a 24 o 32 para una salida de color verdadero.

## Preguntas Frecuentes

**Q: ¿Puedo convertir por lotes varios archivos DWF a PDF?**  
A: Sí – itera sobre una carpeta, carga cada archivo con `Image.Load` y llama a `Save` con opciones PDF dentro del bucle.

**Q: ¿La exportación a BMP conserva las pistas de profundidad 3‑D?**  
A: El rasterizador crea un bitmap plano, pero puedes habilitar sombreado e iluminación mediante `RasterizationOptions` para una profundidad realista.

**Q: ¿Se requiere una licencia para compilaciones de desarrollo?**  
A: Una licencia de evaluación temporal funciona para desarrollo; una licencia completa es obligatoria para despliegues en producción.

**Q: ¿Qué plataformas son compatibles?**  
A: Windows, Linux y macOS son compatibles al ejecutar .NET Core o runtimes .NET 5+.

**Q: ¿Cómo maneja Aspose.CAD los archivos DWF protegidos con contraseña?**  
A: Proporciona la contraseña a través de `LoadOptions.Password` al cargar el archivo fuente.
