# Πώς να χρησιμοποιήσετε το Aspose.CAD για εξαγωγή CAD σε μορφή BMP

## Εισαγωγή

Αν ψάχνετε για **πώς να χρησιμοποιήσετε το Aspose.CAD** για να μετατρέψετε ένα σχέδιο CAD σε εικόνα BMP, βρίσκεστε στο σωστό μέρος. Σε αυτό το tutorial θα περάσουμε από όλη τη ροή εργασίας — από την εγκατάσταση της βιβλιοθήκης μέχρι την εξαγωγή ενός 3‑D αρχείου CAD ως υψηλής ποιότητας bitmap BMP. Στο τέλος θα κατανοήσετε τη διαδικασία **cad file format conversion** και θα είστε έτοιμοι να την ενσωματώσετε στις δικές σας εφαρμογές .NET.

## Γρήγορες απαντήσεις
- **Ποια βιβλιοθήκη απαιτείται;** Aspose.CAD for .NET (download from the official site).  
- **Ποιοι μορφές CAD μπορούν να εξαχθούν;** Over 30 formats, including DWG, DWF, and DXF.  
- **Μπορώ να εξάγω 3‑D μοντέλα;** Yes, Aspose.CAD renders 3‑D geometry to BMP, PNG, JPEG, and more.  
- **Χρειάζομαι άδεια για δοκιμές;** A free temporary license is available for evaluation.  
- **Ποιες εκδόσεις .NET υποστηρίζονται;** .NET Framework 4.5+, .NET Core 2.0+, .NET 5/6/7.

## Τι είναι το Aspose.CAD;

**Aspose.CAD** είναι ένα .NET API που επιτρέπει στους προγραμματιστές να φορτώνουν, να επεξεργάζονται και να μετατρέπουν σχέδια CAD χωρίς την ανάγκη οποιουδήποτε εγγενούς λογισμικού CAD. Υποστηρίζει πάνω από 30 μορφές εισόδου και μπορεί να τα αποδίδει σε raster εικόνες όπως BMP, PNG και JPEG.

## Γιατί να εξάγετε CAD σε BMP;

Το Aspose.CAD μπορεί **export to BMP at a rate of up to 150 Mbps for 100‑page drawings**, διατηρώντας την ακρίβεια των διανυσμάτων ενώ παρέχει μια raster μορφή που υποστηρίζεται καθολικά από τα παλαιά συστήματα. Τα αρχεία BMP είναι ασυμπίεστα, καθιστώντας τα ιδανικά για αλυσίδες επεξεργασίας εικόνας που απαιτούν δεδομένα pixel‑perfect.

## Προαπαιτούμενα

Πριν ξεκινήσουμε, βεβαιωθείτε ότι έχετε:

- **Aspose.CAD for .NET**: Download and install the library from [here](https://releases.aspose.com/cad/net/).  
- **Development Environment**: Οποιαδήποτε πρόσφατη έκδοση του Visual Studio ή του VS Code με εγκατεστημένο .NET SDK.  
- **CAD File**: Ένα αρχείο CAD προέλευσης· αυτό το παράδειγμα χρησιμοποιεί **“18-12-11 9644 - site.dwf”**.

## Πώς να εξάγετε CAD σε BMP χρησιμοποιώντας το Aspose.CAD;

Φορτώστε το αρχείο CAD σας με `Image.Load`, διαμορφώστε τις επιλογές rasterization και καλέστε `Save` για να γράψετε ένα αρχείο BMP. Ολόκληρη η μετατροπή εκτελείται σε μόλις τρεις γραμμές κώδικα, και το Aspose.CAD διαχειρίζεται αυτόματα τη μετατροπή vector‑to‑raster, την κλιμάκωση του πάχους γραμμής και τη διαχείριση του χρώματος φόντου.

## Εισαγωγή ονοματοχώρων

Στο .NET έργο σας, βεβαιωθείτε ότι έχετε εισάγει τους απαραίτητους ονοματοχώρους. Οι δηλώσεις `using` φέρνουν τα απαιτούμενα .NET και Aspose.CAD ονοματοχώρους στο πεδίο ορατότητας.  
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;
using Aspose.CAD;
using Aspose.CAD.ImageOptions;
```

## Βήμα 1: Φόρτωση της εικόνας CAD

Ξεκινήστε φορτώνοντας την εικόνα CAD στο έργο σας. Αντικαταστήστε το **“Your Document Directory”** με το πραγματικό μονοπάτι του καταλόγου. Το `Image` αντιπροσωπεύει ένα σχέδιο CAD που έχει φορτωθεί στη μνήμη και παρέχει μεθόδους για απόδοση και μετατροπή.  
```csharp
string MyDir = "Your Document Directory";
string inputFile = MyDir + "18-12-11 9644 - site.dwf";

using (Image image = Image.Load(inputFile))
{
    // Your code for loading the image goes here
}
```

## Βήμα 2: Διαμόρφωση επιλογών εξαγωγής BMP

Ρυθμίστε τις επιλογές εξαγωγής BMP, συμπεριλαμβανομένων των επιλογών rasterization διανυσμάτων για αρχεία CAD. Το `BmpOptions` καθορίζει τις ρυθμίσεις εξόδου BMP, ενώ το `CadRasterizationOptions` ελέγχει πώς rasterize τα διανύσματα CAD.  
```csharp
BmpOptions bmpOptions = new BmpOptions();
var dwfRasterizationOptions = new CadRasterizationOptions();
bmpOptions.VectorRasterizationOptions = dwfRasterizationOptions;

dwfRasterizationOptions.PageHeight = 500;
dwfRasterizationOptions.PageWidth = 500;
```

## Βήμα 3: Εξαγωγή σε BMP

Εκτελέστε τη διαδικασία εξαγωγής, καθορίζοντας τη διαδρομή εξόδου για το αρχείο BMP. Η `Save` γράφει την εικόνα στο καθορισμένο αρχείο χρησιμοποιώντας τις παρεχόμενες επιλογές εξαγωγής.  
```csharp
string outPath = MyDir + "18-12-11 9644 - site.bmp";
image.Save(outPath, bmpOptions);
```

## Κοινά προβλήματα και λύσεις

- **Blank BMP output** – Βεβαιωθείτε ότι το αντικείμενο `VectorRasterizationOptions` καθορίζει μη‑μηδενικό `PageWidth` και `PageHeight`.  
- **Incorrect colours** – Ορίστε το `BackgroundColor` στο `BmpOptions` ώστε να ταιριάζει με το επιθυμητό χρώμα καμβά.  
- **Large files cause memory pressure** – Χρησιμοποιήστε `LoadOptions` με `LoadMode = LoadMode.Stream` για να επεξεργαστείτε το αρχείο CAD με τρόπο streaming.
