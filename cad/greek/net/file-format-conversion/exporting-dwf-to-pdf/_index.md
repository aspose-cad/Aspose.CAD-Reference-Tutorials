## Πώς να μετατρέψω DWF σε PDF με το Aspose.CAD;

Φορτώστε το πηγαίο DWF χρησιμοποιώντας `Image.Load`, διαμορφώστε τις επιλογές rasterization και καλέστε `Save` με μορφή PDF – αυτή είναι η πλήρης μετατροπή σε τρία απλά βήματα. Η βιβλιοθήκη διαχειρίζεται αυτόματα τα διανυσματικά γραφικά, τα επίπεδα και τα μεταδεδομένα, ώστε το παραγόμενο PDF να φαίνεται ταυτόσημο με το αρχικό σχέδιο.

## Εισαγωγή Ονομάτων Χώρων

Οι παρακάτω ονομασίες χώρων (namespaces) παρέχουν πρόσβαση στη βασική λειτουργικότητα του Aspose.CAD και στις επιλογές PDF.
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;
using Aspose.CAD;
using Aspose.CAD.ImageOptions;
```

## Βήμα 1: Φόρτωση του Αρχείου DWF

Η κλάση `Image` αντιπροσωπεύει μια εικόνα CAD και παρέχει μεθόδους για τη φόρτωση και τη διαχείρισή της.
```csharp
string MyDir = "Your Document Directory";
string fileName = MyDir + "18-12-11 9644 - site.dwf";

using (Image image = Image.Load(fileName))
{
    // Your code here...
}
```

## Βήμα 2: Διαμόρφωση Επιλογών Rasterization

`CadRasterizationOptions` ορίζει πώς rasterize (αποδοχή) τα σχέδια CAD, συμπεριλαμβανομένου του μεγέθους σελίδας και της ανάλυσης.
```csharp
CadRasterizationOptions dwfRasterizationOptions = new CadRasterizationOptions();
dwfRasterizationOptions.PageHeight = 500;
dwfRasterizationOptions.PageWidth = 500;
```

## Βήμα 3: Ορισμός Επιλογών PDF

`PdfOptions` καθορίζει τις ρυθμίσεις εξόδου PDF για τη διαδικασία μετατροπής.
```csharp
PdfOptions pdfOptions = new PdfOptions();
pdfOptions.VectorRasterizationOptions = dwfRasterizationOptions;
```

## Βήμα 4: Εξαγωγή σε PDF

Η μέθοδος `Save` γράφει την φορτωμένη εικόνα στη συγκεκριμένη μορφή και διαδρομή.
```csharp
string outPath = MyDir + "18-12-11 9644 - site.pdf";
image.Save(outPath, pdfOptions);
```

## Βήμα 5: Επαλήθευση της Εξαγωγής

Βεβαιωθείτε για την επιτυχή εξαγωγή των 3D εικόνων σε PDF. Εμφανίστε ένα μήνυμα επιβεβαίωσης με τη διαδρομή του αποθηκευμένου αρχείου.
```csharp
Console.WriteLine("\n3D images exported successfully to PDF.\nFile saved at " + MyDir);
```

## Συχνά Προβλήματα και Λύσεις

- **Κενές σελίδες στο PDF** – Επαληθεύστε ότι οι τιμές `PageWidth` και `PageHeight` ταιριάζουν με τις διαστάσεις του πηγαίου DWF.
- **Λείπουν επίπεδα** – Βεβαιωθείτε ότι το `RasterizationOptions` έχει το `VectorRasterizationOptions` ορισμένο σε `true` για να διατηρηθούν τα διανυσματικά δεδομένα.
- **Σφάλματα έλλειψης μνήμης σε μεγάλα αρχεία** – Ενεργοποιήστε το `LoadOptions` με `MemorySaving` για επεξεργασία αρχείων σε λειτουργία ροής.
