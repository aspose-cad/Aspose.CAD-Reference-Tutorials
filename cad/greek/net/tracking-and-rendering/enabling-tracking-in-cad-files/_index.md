# Πώς να μετατρέψετε αρχείο CAD σε PDF και να ενεργοποιήσετε την παρακολούθηση

## Εισαγωγή

Η μετατροπή ενός αρχείου CAD σε PDF διατηρώντας πλήρη πληροφορία παρακολούθησης είναι απαραίτητη για ροές εργασίας μηχανικής με έλεγχο ποιότητας. Σε αυτό το tutorial θα μάθετε πώς να **convert CAD file to PDF** και να ενεργοποιήσετε την παρακολούθηση χρησιμοποιώντας το Aspose.CAD για .NET, εξασφαλίζοντας ακριβή απόδοση και λεπτομερείς αναφορές σφαλμάτων καθ' όλη τη διαδικασία εξαγωγής.

## Γρήγορες απαντήσεις
- **Τι παρέχει η παρακολούθηση;** Καταγράφει προειδοποιήσεις και σφάλματα απόδοσης, βοηθώντας σας να εντοπίσετε προβληματικές οντότητες στο αρχικό αρχείο CAD.  
- **Ποιοι μορφές υποστηρίζονται;** Το Aspose.CAD διαχειρίζεται πάνω από 30 μορφές εισόδου CAD και μπορεί να εξάγει σε PDF, SVG, PNG και άλλα.  
- **Χρειάζομαι άδεια;** Μια προσωρινή άδεια λειτουργεί για αξιολόγηση· απαιτείται πλήρης άδεια για παραγωγική χρήση.  
- **Ποιες εκδόσεις .NET είναι συμβατές;** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7 υποστηρίζονται πλήρως.  
- **Πόσο διαρκεί η μετατροπή;** Τυπικά αρχεία DXF κάτω από 5 MB μετατρέπονται σε λιγότερο από ένα δευτερόλεπτο σε τυπικό υλικό.

## Τι είναι η μετατροπή αρχείου CAD σε PDF;
**Convert CAD file to PDF** είναι η διαδικασία απόδοσης ενός σχεδίου CAD (όπως DXF ή DWG) σε έγγραφο PDF διατηρώντας την ακρίβεια των διανυσματικών στοιχείων και προαιρετικά τα μεταδεδομένα παρακολούθησης. Αυτή η λειτουργία σας επιτρέπει να μοιράζεστε ακριβείς, μόνο για ανάγνωση, αναπαραστάσεις των σχεδίων με ενδιαφερόμενους που ενδέχεται να μην διαθέτουν λογισμικό CAD.

## Γιατί να ενεργοποιήσετε την παρακολούθηση κατά τη μετατροπή αρχείου CAD σε PDF;
Η ενεργοποίηση της παρακολούθησης καταγράφει λεπτομερή διαγνωστικά απόδοσης — ελλιπείς γραμματοσειρές, μη υποστηριζόμενες οντότητες ή σφάλματα γεωμετρίας — ώστε να μπορείτε να αντιμετωπίσετε τα προβλήματα πριν από την τελική διανομή. Το Aspose.CAD καταγράφει έως και 1.000 προειδοποιήσεις ανά μετατροπή και τις αναφέρει στο αρχείο καταγραφής `PdfExportOptions`, μειώνοντας την επαναεργασία έως και 40 % σε μεγάλα έργα μηχανικής.

## Προαπαιτούμενα

Πριν ξεκινήσετε, βεβαιωθείτε ότι έχετε τα εξής:

- **Aspose.CAD for .NET** – κατεβάστε τη νεότερη βιβλιοθήκη από την επίσημη ιστοσελίδα [Aspose.CAD for .NET download page](https://releases.aspose.com/cad/net/).  
- **A CAD document** – για αυτόν τον οδηγό θα χρησιμοποιήσουμε το `conic_pyramid.dxf`.  
- **A writable directory** – αντικαταστήστε το σύμβολο κράτησης θέσης “Your Document Directory” στον κώδικα δείγματος με πραγματική διαδρομή στον υπολογιστή σας.  

Έχοντας αυτά τα στοιχεία έτοιμα, μπορείτε να ακολουθήσετε τα βήματα χωρίς διακοπή.

## Εισαγωγή ονομάτων χώρου

Οι παρακάτω `using` οδηγίες φέρνουν τα απαιτούμενα ονόματα χώρου Aspose.CAD στο πεδίο εφαρμογής.  
```csharp
using Aspose.CAD.ImageOptions;
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Text;
```

## Βήμα 1: Φόρτωση της εικόνας CAD

Η φόρτωση του πηγαίου αρχείου δημιουργεί μια αναπαράσταση στη μνήμη που το Aspose.CAD μπορεί να χειριστεί. Το αντικείμενο `Image` ανιχνεύει αυτόματα τη μορφή του αρχείου και το προετοιμάζει για εξαγωγή.  
```csharp
string MyDir = "Your Document Directory";
using (Image image = Image.Load(MyDir + "conic_pyramid.dxf"))
{
    // Code for the next steps will be added here
}
```

## Βήμα 2: Ρύθμιση επιλογών εξαγωγής PDF

`PdfExportOptions` σας επιτρέπει να ρυθμίσετε λεπτομερώς την έξοδο PDF, συμπεριλαμβανομένου του μεγέθους σελίδας, της ανάλυσης και των ρυθμίσεων παρακολούθησης. Διαμορφώνοντας την ιδιότητα `TrackWarnings` ενεργοποιείτε λεπτομερή καταγραφή τυχόν προβλημάτων απόδοσης.  
```csharp
using (FileStream stream = new FileStream(MyDir + "output_conic_pyramid.pdf", FileMode.Create))
{
    PdfOptions pdfOptions = new PdfOptions();
    CadRasterizationOptions cadRasterizationOptions = new CadRasterizationOptions();
    pdfOptions.VectorRasterizationOptions = cadRasterizationOptions;
    cadRasterizationOptions.PageWidth = 800;
    cadRasterizationOptions.PageHeight = 600;
```

## Βήμα 3: Υλοποίηση παρακολούθησης

Όταν η παρακολούθηση είναι ενεργοποιημένη, το Aspose.CAD γράφει ένα αρχείο προειδοποιήσεων στο αντικείμενο `PdfExportOptions`. Μετά τη μετατροπή μπορείτε να εξετάσετε το `options.Warnings` για να δείτε τη λίστα όλων των καταγεγραμμένων μηνυμάτων.  
```csharp
    int idxError = 1;
    cadRasterizationOptions.RenderResult += new CadRasterizationOptions.CadRenderHandler(
        delegate (CadRenderResult result)
        {
            Console.WriteLine("Tracking results of exporting");
            if (result.IsRenderComplete)
                return;
            Console.WriteLine("Have some problems:");
            foreach (RenderResult rr in result.Failures)
                Console.WriteLine(string.Format("{0}. {1}, {2}", idxError++, rr.RenderCode.ToString(), rr.Message));
        });
```

## Βήμα 4: Αποθήκευση σε μορφή PDF

Τέλος, καλέστε τη μέθοδο `Save` στο αντικείμενο `Image`, περνώντας τις ρυθμισμένες `PdfExportOptions`. Το παραγόμενο αρχείο PDF περιέχει τόσο την οπτική απόδοση όσο και τα ενσωματωμένα μεταδεδομένα παρακολούθησης.  
```csharp
    Console.WriteLine("Exporting to pdf format");
    image.Save(stream, pdfOptions);
}
```

## Κοινά προβλήματα και λύσεις

- **Missing fonts** – Βεβαιωθείτε ότι οι απαιτούμενες γραμματοσειρές TrueType είναι εγκατεστημένες στον διακομιστή ή παρέχετε έναν προσαρμοσμένο φάκελο γραμματοσειρών μέσω `options.FontsPath`.  
- **Unsupported entities** – Εξετάστε το αρχείο προειδοποιήσεων· οι οντότητες που δεν μπορούν να αποδοθούν εμφανίζονται με το επίπεδο και τα IDs αντικειμένων τους.  
- **Large files (> 2 GB)** – Χρησιμοποιήστε τον κατασκευαστή `LoadOptions` με `LoadMode.Streaming` για να αποφύγετε τη φόρτωση ολόκληρου του αρχείου στη μνήμη.
