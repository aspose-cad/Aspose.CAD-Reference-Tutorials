- **Χρειάζομαι άδεια για παραγωγική χρήση;** Ναι, απαιτείται εμπορική άδεια Aspose.CAD για μη‑δοκιμαστικές εγκαταστάσεις.

## Τι είναι η μορφή αρχείου STL;
Η μορφή STL (Stereolithography) κωδικοποιεί την επιφάνεια ενός 3‑D αντικειμένου ως ένα πλέγμα τριγωνικών όψεων. Είναι το de‑facto πρότυπο για 3‑D εκτύπωση και πολλές διαδικασίες CAD, επειδή αποθηκεύει τη γεωμετρία χωρίς πληροφορίες χρώματος ή υφής. Τα αρχεία STL περιέχουν μόνο συντεταγμένες κορυφών και κανονικές όψεων, καθιστώντας τα ελαφριά και εύκολα στην ανταλλαγή μεταξύ πλατφορμών.

## Γιατί να χρησιμοποιήσετε το Aspose.CAD για .NET;
Το Aspose.CAD υποστηρίζει **100+** μορφές αρχείων CAD και BIM, συμπεριλαμβανομένων των DWG, DXF, DGN και STL. Μπορεί να αποδίδει αρχεία έως **2 GB** σε μέγεθος διατηρώντας την κατανάλωση μνήμης κάτω από **150 MB** μέσω ροής δεδομένων. Η βιβλιοθήκη προσφέρει επίσης **30+** επιλογές απόδοσης (χρώμα φόντου, DPI, anti‑aliasing) που σας επιτρέπουν να ρυθμίσετε λεπτομερώς την έξοδο PNG για web ή εκτύπωση.

## Πώς να μετατρέψετε STL σε PNG;
`Image.Load` διαβάζει το αρχείο STL και δημιουργεί ένα αντικείμενο Aspose.CAD `Image` που αντιπροσωπεύει το 3‑D μοντέλο στη μνήμη. `PngOptions` ορίζει τις ρυθμίσεις της raster‑εικόνας όπως ανάλυση, χρώμα φόντου και επίπεδο συμπίεσης. Τέλος, το `Image.Save` γράφει την αποδοθείσα προβολή σε ένα αρχείο PNG χρησιμοποιώντας τις παρεχόμενες επιλογές. Μια τυπική μετατροπή φαίνεται ως εξής:

```csharp
// Load the STL file
var image = Image.Load("model.stl");

// Configure PNG output
var pngOptions = new PngOptions
{
    ResolutionX = 300,
    ResolutionY = 300,
    BackgroundColor = Color.White
};

// Save as PNG
image.Save("preview.png", pngOptions);
```
