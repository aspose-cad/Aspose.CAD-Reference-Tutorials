## Πώς να προσθέσω ένα υδατογράφημα σε σχέδιο CAD;

Απλώς φορτώνετε το αρχείο CAD, δημιουργείτε μια οντότητα υδατογραφήματος (MTEXT ή Text), την προσθέτετε στο χώρο μοντέλου και, στη συνέχεια, αποθηκεύετε την εικόνα στην επιθυμητή μορφή όπως PDF. Αυτή η προσέγγιση λειτουργεί για οποιονδήποτε υποστηριζόμενο μορφότυπο CAD και μπορεί να προγραμματιστεί για μαζική επεξεργασία.

## Εισαγωγή ονοματοχώρων

`using Aspose.CAD;`  
`using Aspose.CAD.ImageOptions;`  
`using Aspose.CAD.FileFormats.Cad;`  

## Βήμα 1: Φόρτωση του σχεδίου CAD

Η κλάση `CadImage` αντιπροσωπεύει ένα σχέδιο CAD που έχει φορτωθεί στη μνήμη και παρέχει πρόσβαση στις οντότητές του.  
```markdown
```csharp
using Aspose.CAD.FileFormats.Cad;
using Aspose.CAD.FileFormats.Cad.CadObjects;
using Aspose.CAD.ImageOptions;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
```
```

```markdown
```csharp
// The path to the documents directory.
string MyDir = "Your Document Directory";

```
```

## Βήμα 3: Ή προσθήκη υδατογραφήματος ως απλό κείμενο

`CadText` αντιπροσωπεύει μια οντότητα κειμένου μίας γραμμής που μπορεί να τοποθετηθεί στο χώρο μοντέλου του σχεδίου.  
```markdown
```csharp
// Add new MTEXT
CadMText watermark = new CadMText();
watermark.Text = "Watermark message";
watermark.InitialTextHeight = 40;
watermark.InsertionPoint = new Cad3DPoint(300, 40);
watermark.LayerName = "0";
cadImage.BlockEntities["*Model_Space"].AddEntity(watermark);
```
```

## Βήμα 4: Εξαγωγή σε PDF

`CadRasterizationOptions` ορίζει πώς θα γίνει η rasterization ενός σχεδίου CAD, ενώ το `PdfOptions` καθορίζει τις ρυθμίσεις εξόδου PDF.  
```markdown
```csharp
// Alternatively, add a simpler entity like Text
CadText text = new CadText();
text.DefaultValue = "Watermark text";
text.TextHeight = 40;
text.FirstAlignment = new Cad3DPoint(300, 40);
text.LayerName = "0";
cadImage.BlockEntities["*Model_Space"].AddEntity(text);
```
```

Επαναλάβετε αυτά τα βήματα για κάθε σχέδιο στη συλλογή σας, και θα δημιουργήσετε επαγγελματικά, υδατογραφημένα αρχεία CAD έτοιμα για διανομή.

## Κοινά προβλήματα και λύσεις

- **Το υδατογράφημα δεν είναι ορατό μετά την εξαγωγή** – Βεβαιωθείτε ότι η ιδιότητα `Opacity` της οντότητας MTEXT ή Text είναι ορισμένη μεταξύ 0.3 και 0.7· τιμές εκτός αυτού του εύρους μπορεί να εμφανιστούν πλήρως αδιαφανείς ή αόρατες.  
- **Τα μεγάλα αρχεία προκαλούν αυξήσεις μνήμης** – Χρησιμοποιήστε το `Image.Load` με την παράμετρο `LoadOptions` για να ενεργοποιήσετε τη ροή, που διατηρεί τη χρήση μνήμης χαμηλή.  
- **Λανθασμένη απόδοση γραμματοσειράς** – Εγκαταστήστε τις ίδιες γραμματοσειρές TrueType στον διακομιστή που χρησιμοποιήθηκαν όταν δημιουργήθηκε το σχέδιο, ή ενσωματώστε μια εναλλακτική γραμματοσειρά μέσω `MText.Font`.
