# Εφαρμογή άδειας Aspose CAD χρησιμοποιώντας FileStream στο .NET

## Εισαγωγή

Σε αυτό το μάθημα θα μάθετε πώς να **εφαρμόσετε την άδεια Aspose CAD** χρησιμοποιώντας ένα αντικείμενο `FileStream`, ώστε η εφαρμογή .NET σας να αξιοποιήσει πλήρως τις δυνατότητες CAD και BIM της βιβλιοθήκης. Η σωστή εφαρμογή της άδειας αφαιρεί τα υδατογράμματα αξιολόγησης και ενεργοποιεί όλες τις premium λειτουργίες.

## Γρήγορες απαντήσεις
- **Τι ξεκλειδώνει η εφαρμογή μιας άδειας;** Πλήρη πρόσβαση σε όλες τις λειτουργίες, χωρίς περιορισμούς αξιολόγησης, και υψηλότερη απόδοση για μεγάλα αρχεία CAD.  
- **Ποια κλάση διαχειρίζεται την άδεια;** Η κλάση `License` στον χώρο ονομάτων Aspose.CAD.  
- **Χρειάζομαι FileStream;** Η χρήση του `FileStream` σας επιτρέπει να φορτώσετε την άδεια από οποιαδήποτε τοποθεσία, συμπεριλαμβανομένων των ενσωματωμένων πόρων.  
- **Είναι δυνατή η δοκιμαστική άδεια;** Ναι – μια δωρεάν δοκιμαστική άδεια λειτουργεί με τον ίδιο τρόπο όπως μια αγορασμένη.  
- **Ποιες εκδόσεις .NET υποστηρίζονται;** .NET Framework 4.5+, .NET Core 3.1+, και .NET 5/6/7.

## Τι σημαίνει η εφαρμογή άδειας Aspose CAD;
Η κλάση `License` είναι το στοιχείο του Aspose.CAD που επικυρώνει την αγορά σας και ενεργοποιεί το πλήρες προϊόν. Η φόρτωσή της μέσω `FileStream` εξασφαλίζει ότι η άδεια μπορεί να διαβαστεί από δίσκο, μνήμη ή ενσωματωμένους πόρους χωρίς σκληρή κωδικοποίηση διαδρομών.

Το Aspose.CAD υποστηρίζει **150+** μορφές CAD και BIM και μπορεί να επεξεργαστεί αρχεία έως **2 GB** χωρίς να φορτώνει ολόκληρο το έγγραφο στη μνήμη. Η χρήση του `FileStream` σας δίνει λεπτομερή έλεγχο του τρόπου ανάγνωσης του αρχείου άδειας, κάτι που είναι ιδιαίτερα χρήσιμο σε περιβάλλοντα cloud ή sandbox.

## Πώς να εφαρμόσετε άδεια Aspose CAD χρησιμοποιώντας FileStream;

Η κλάση `License` χρησιμοποιείται για την εφαρμογή άδειας στο Aspose.CAD, και η μέθοδος `SetLicense` της φορτώνει την άδεια από ένα ρεύμα (stream). Φορτώστε το αρχείο άδειας με ένα `FileStream`, δημιουργήστε ένα αντικείμενο `License` και καλέστε το `SetLicense`. Αυτό το τρι-βήμα μοτίβο λειτουργεί σε εφαρμογές κονσόλας, υπηρεσίες Windows και έργα ASP.NET Core, και εγγυάται ότι η άδεια εφαρμόζεται πριν ξεκινήσει οποιαδήποτε επεξεργασία CAD.

### Βήμα 1: ορίστε τη διαδρομή του αρχείου άδειας

Ξεκινήστε ορίζοντας τη διαδρομή του αρχείου άδειας Aspose.CAD. Σε αυτό το παράδειγμα υποθέτουμε ότι βρίσκεται στον φάκελο **c:\\temp\\**.

```csharp
string dataDir = @"c:\temp\";
```

### Βήμα 2: φορτώστε το αρχείο άδειας σε FileStream

Στη συνέχεια, δημιουργήστε ένα `FileStream` για την ανάγνωση του αρχείου άδειας. Το ρεύμα μπορεί να ανοιχτεί με πρόσβαση μόνο για ανάγνωση, διασφαλίζοντας ότι το αρχείο παραμένει αμετάβλητο.

```csharp
FileStream LicStream = new FileStream(dataDir + "Aspose.CAD.lic", FileMode.Open);
```

### Βήμα 3: εφαρμόστε την άδεια

Τώρα, δημιουργήστε μια παρουσία της κλάσης `License` και ορίστε την άδεια χρησιμοποιώντας τη μέθοδο `SetLicense`. Μόλις αυτή η κλήση ολοκληρωθεί επιτυχώς, όλες οι επόμενες λειτουργίες του Aspose.CAD εκτελούνται χωρίς περιορισμούς αξιολόγησης.

```csharp
License license = new License();
license.SetLicense(LicStream);
```

## Συνηθισμένα προβλήματα και αντιμετώπιση

- **File not found** – Επαληθεύστε ότι η διαδρομή είναι σωστή και ότι η εφαρμογή έχει δικαιώματα ανάγνωσης στο φάκελο.  
- **Invalid license format** – Βεβαιωθείτε ότι το αρχείο άδειας είναι το ακριβές αρχείο `.lic` που παρέχει η Aspose και δεν έχει τροποποιηθεί.  
- **Multiple threads loading the license** – Φορτώστε την άδεια μία φορά κατά την εκκίνηση της εφαρμογής για να αποφύγετε περιττές εισόδους/εξόδους.
