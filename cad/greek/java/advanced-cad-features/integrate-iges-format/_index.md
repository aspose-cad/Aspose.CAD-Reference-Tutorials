## Πώς να φορτώσετε IGES σε Java;

Για να φορτώσετε ένα αρχείο IGES, καλέστε τη στατική μέθοδο `load` της κλάσης `Image`, περνώντας τη πλήρη διαδρομή του πηγαίου αρχείου. Αυτό δημιουργεί μια εν-μνήμης αναπαράσταση του σχεδίου CAD, επιτρέποντάς σας να ελέγξετε τις ιδιότητές του και αργότερα να το rasterize στο επιθυμητό μορφότυπο.

```text
```java
import com.aspose.cad.Image;
import com.aspose.cad.Image;

import com.aspose.cad.imageoptions.CadRasterizationOptions;
import com.aspose.cad.imageoptions.PdfOptions;
```
```

> **Συμβουλή:** Η διπλή γραμμή `import com.aspose.cad.Image;` που μερικές φορές εμφανίζεται σε παραδείγματα είναι ακίνδυνη, αλλά μπορεί να αφαιρεθεί για πιο καθαρό αρχείο.

## Πώς να δημιουργήσετε προσαρμοσμένη σελίδα PDF από IGES;

Η δημιουργία προσαρμοσμένης σελίδας PDF απαιτεί τον ορισμό επιλογών rasterization που καθορίζουν το πλάτος, το ύψος, το DPI και το χρώμα φόντου της σελίδας. Ρυθμίζοντας αυτές τις παραμέτρους μπορείτε να ταιριάξετε τυπικά μεγέθη χαρτιού όπως A4 ή να δημιουργήσετε διαστάσεις αφίσας, εξασφαλίζοντας ότι το αποδομένο σχέδιο ταιριάζει ακριβώς στην επιθυμητή διάταξη.

`CadRasterizationOptions` είναι το δοχείο ρυθμίσεων που λέει στο Aspose.CAD πώς να rasterize ένα σχέδιο CAD—πλάτος σελίδας, ύψος, DPI και λειτουργία απόδοσης.  

```text
```java
String sourceFilePath = dataDir + "figa2.igs";
Image igesImage = Image.load(sourceFilePath);
```
```

Στο παράδειγμα ορίζουμε τόσο το `PageHeight` όσο και το `PageWidth` στα **1000 pixels**, αλλά μπορείτε να αλλάξετε αυτές τις τιμές σε οποιοδήποτε μέγεθος απαιτείται από τα πρότυπα τεκμηρίωσής σας, όπως A4 (595 × 842 pt) ή προσαρμοσμένες διαστάσεις αφίσας.

## Πώς να αποθηκεύσετε το παραγόμενο PDF;

`PdfOptions` ορίζει παραμέτρους ειδικές για PDF όπως συμπίεση και ρυθμίσεις rasterization vector. Μετά τη διαμόρφωση των `CadRasterizationOptions`, αντιστοιχίστε τις στην παρουσία `PdfOptions` και καλέστε τη μέθοδο `save` του αντικειμένου `Image`, παρέχοντας τη διαδρομή εξόδου και το αντικείμενο επιλογών.

Η μέθοδος `save` γράφει την εν-μνήμης εικόνα στο επιλεγμένο μορφότυπο, εφαρμόζοντας όλες τις προηγούμενα ορισμένες επιλογές rasterization.  

```text
```java
String outPath = dataDir + "meshes.pdf";
PdfOptions pdf = new PdfOptions();
CadRasterizationOptions vectorOptions = new CadRasterizationOptions();
vectorOptions.setPageHeight(1000);
vectorOptions.setPageWidth(1000);
pdf.setVectorRasterizationOptions(vectorOptions);
```
```

Μετά από αυτήν την κλήση, ένα πλήρως αποδομένο PDF εμφανίζεται στον φάκελο `dataDir`, έτοιμο για διανομή ή περαιτέρω επεξεργασία.

| **Λανθασμένα χρώματα ή πάχη γραμμών** | Ορίστε `CadRasterizationOptions.setBackgroundColor(Color.WHITE)` και προσαρμόστε το `setScale` εάν το σχέδιο εμφανίζεται πολύ μικρό ή πολύ μεγάλο. |
