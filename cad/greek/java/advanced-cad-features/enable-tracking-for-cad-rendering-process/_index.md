# Ενεργοποίηση παρακολούθησης για τη διαδικασία απόδοσης CAD

## Εισαγωγή

Σε αυτό το σεμινάριο θα μάθετε πώς να **ορίσετε το μέγεθος σελίδας PDF** ενώ **μετατρέπετε CAD σε PDF** χρησιμοποιώντας **Aspose.CAD for Java**. Ενεργοποιώντας την παρακολούθηση αποκτάτε πλήρη ορατότητα πάνω στην αλυσίδα απόδοσης, καθιστώντας πιο εύκολο τον εντοπισμό σφαλμάτων και τη βελτιστοποίηση της μετατροπής από αρχεία CAD (όπως DXF) σε PDF. Είτε χρειάζεστε **αποθήκευση CAD ως PDF**, δημιουργία PDF από DXF, ή απλώς έλεγχο των διαστάσεων εξόδου, τα παρακάτω βήματα θα σας καθοδηγήσουν σε όλη τη διαδικασία.

## Γρήγορες απαντήσεις

- **Τι κάνει η «ορισμός μεγέθους σελίδας PDF»;** Ορίζει το πλάτος και το ύψος της τελικής σελίδας PDF κατά την απόδοση CAD.  
- **Γιατί να ενεργοποιήσετε την παρακολούθηση;** Η παρακολούθηση καταγράφει κάθε στάδιο της μετατροπής, βοηθώντας σας να εντοπίσετε σημεία συμφόρησης ή σφάλματα απόδοσης.  
- **Χρειάζομαι άδεια;** Μια δωρεάν δοκιμή λειτουργεί για αξιολόγηση· απαιτείται εμπορική άδεια για παραγωγή.  
- **Ποιοι μορφές CAD υποστηρίζονται;** DWG, DXF, DGN και πολλές άλλες – δείτε την τεκμηρίωση Aspose.CAD για την πλήρη λίστα.  
- **Μπορώ να αλλάξω τις διαστάσεις της σελίδας εν κινήσει;** Ναι – απλώς προσαρμόστε τις τιμές `PageWidth` και `PageHeight` στο `CadRasterizationOptions`.  

## Τι είναι η «ορισμός μεγέθους σελίδας PDF» στην απόδοση CAD;

Ο ορισμός του μεγέθους σελίδας PDF λέει στον rasterizer πόσο μεγάλο πρέπει να είναι το καμβά όταν τα διανυσματικά δεδομένα CAD μετατρέπονται σε σελίδα PDF. Αυτό είναι κρίσιμο για τη διατήρηση της οπτικής πιστότητας, ειδικά όταν εργάζεστε με λεπτομερή τεχνικά σχέδια. Η επιλογή κατάλληλων διαστάσεων εξασφαλίζει ότι το σχέδιο κλιμακώνεται σωστά και ότι οι σημειώσεις παραμένουν αναγνώσιμες.

## Γιατί να ενεργοποιήσετε την παρακολούθηση για την απόδοση CAD;

Η ενεργοποίηση της παρακολούθησης παρέχει ένα λεπτομερές αρχείο καταγραφής κάθε βήματος—από τη φόρτωση του αρχείου προέλευσης μέχρι τη δημιουργία του PDF. Βοηθάει: Το αρχείο περιλαμβάνει χρονικές σημάνσεις, χρήση μνήμης και λεπτομέρειες rasterization, επιτρέποντας στους προγραμματιστές να εντοπίζουν σημεία συμφόρησης απόδοσης και ανωμαλίες απόδοσης. Ανασκοπώντας αυτές τις πληροφορίες μπορείτε να προσαρμόσετε ρυθμίσεις όπως το μέγεθος σελίδας ή η ανάλυση για να βελτιώσετε την ποιότητα εξόδου.

## Προαπαιτούμενα

Πριν ξεκινήσετε τη ρύθμιση της παρακολούθησης, βεβαιωθείτε ότι διαθέτετε τα παρακάτω προαπαιτούμενα:

1. **Java development environment** – Java 8 ή νεότερη έκδοση εγκατεστημένη στο σύστημά σας.  
2. **Aspose.CAD library** – Κατεβάστε και ενσωματώστε τη βιβλιοθήκη Aspose.CAD στο έργο Java. Μπορείτε να βρείτε τον σύνδεσμο λήψης [Aspose.CAD Java download page](https://releases.aspose.com/cad/java/).  
3. **Document directory** – Προετοιμάστε έναν φάκελο για την αποθήκευση των αρχείων CAD και των παραγόμενων PDF.  

## Εισαγωγή ονοματοχώρων

Το `Aspose.CAD` παρέχει τις βασικές κλάσεις που χρησιμοποιούνται για τη φόρτωση, rasterisation και αποθήκευση σχεδίων CAD. Εισάγετε τα απαιτούμενα πακέτα στην αρχή του αρχείου πηγαίου κώδικα Java.

```java
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.OutputStream;

import com.aspose.cad.Image;

import com.aspose.cad.imageoptions.CadRasterizationOptions;
import com.aspose.cad.imageoptions.PdfOptions;
```

## Ορισμός διαδρομής φακέλου πόρων

Η κλάση `File` (java.io.File) αντιπροσωπεύει μια διαδρομή αρχείου ή φακέλου στο σύστημα αρχείων. Η κλάση `File` από το `java.io` αντιπροσωπεύει το φάκελο που περιέχει τα πηγαία αρχεία CAD. Καθορίστε τη σωστή τοποθεσία πριν φορτώσετε οποιοδήποτε σχέδιο.

```java
String dataDir = "Your Document Directory" + "CADConversion/";
```

## Φόρτωση αρχείου CAD

Το `CadImage` είναι η κλάση Aspose.CAD που φορτώνει και αντιπροσωπεύει ένα σχέδιο CAD για περαιτέρω επεξεργασία. Το `CadImage` είναι το σημείο εισόδου για την ανάγνωση ενός εγγράφου CAD. Αναλύει τη μορφή του αρχείου και προετοιμάζει τον rasterizer.

```java
String srcFile = dataDir + "conic_pyramid.dxf";
Image image = Image.load(srcFile);
```

## Ορισμός επιλογών εξόδου PDF

Το `PdfOptions` διαμορφώνει ρυθμίσεις ειδικές για PDF όπως συμπίεση, μεταδεδομένα και διαχείριση ροής εξόδου. Το `PdfOptions` περιλαμβάνει όλες τις ρυθμίσεις ειδικές για PDF όπως συμπίεση, μεταδεδομένα και διαχείριση ροής εξόδου.

```java
OutputStream stream = new FileOutputStream(dataDir + "conic_pyramid.pdf");
PdfOptions pdfOptions = new PdfOptions();
```

## Διαμόρφωση CadRasterizationOptions (ορισμός μεγέθους σελίδας PDF)

Το `CadRasterizationOptions` ελέγχει τις παραμέτρους rasterisation όπως το μέγεθος σελίδας, η ανάλυση και η μορφή εξόδου για τη μετατροπή CAD σε PDF. Το `CadRasterizationOptions` είναι η κλάση που ελέγχει τις παραμέτρους rasterisation όπως το μέγεθος σελίδας, η ανάλυση και η μορφή εξόδου. Ορίζοντας τις τιμές `PageWidth` και `PageHeight` καθορίζετε τις ακριβείς διαστάσεις της παραγόμενης σελίδας PDF.

```java
CadRasterizationOptions cadRasterizationOptions = new CadRasterizationOptions();
pdfOptions.setVectorRasterizationOptions(cadRasterizationOptions);
cadRasterizationOptions.setPageWidth(800);
cadRasterizationOptions.setPageHeight(600);
```

## Αποθήκευση αρχείου PDF

Η μέθοδος `save` γράφει το rasterised περιεχόμενο στη συγκεκριμένη ροή εξόδου χρησιμοποιώντας τις παρεχόμενες επιλογές PDF. Καλώντας `image.save(outputStream, pdfOptions)` γράφει το rasterised περιεχόμενο σε ροή PDF χρησιμοποιώντας τις ρυθμίσεις που διαμορφώσατε.

```java
image.save(stream, pdfOptions);
```

## Επαλήθευση ενεργοποίησης παρακολούθησης

Η `setTrackingEnabled(true)` ενεργοποιεί λεπτομερή καταγραφή κάθε σταδίου απόδοσης εντός του rasterizer. Η `CadRasterizationOptions.setTrackingEnabled(true)` ενεργοποιεί λεπτομερή καταγραφή για κάθε στάδιο απόδοσης, επιτρέποντάς σας να εξετάσετε τη εσωτερική ροή εργασίας.

```java
System.out.println("Tracking enabled successfully for CAD rendering process.");
```

## Κοινά προβλήματα & αντιμετώπιση

| Συμπτωμα | Πιθανή αιτία | Διόρθωση |
|----------|--------------|----------|
| Η σελίδα PDF εμφανίζεται κενή | `PageWidth`/`PageHeight` set to 0 | Βεβαιωθείτε ότι παρέχονται διαστάσεις διαφορετικές του μηδενός. |
| Το αρχείο εξόδου είναι κατεστραμμένο | Output stream not closed | Καλέστε `stream.close()` μετά το `image.save(...)`. |
| Απουσία στρωμάτων στο PDF | CAD file uses unsupported entities | Επαληθεύστε ότι η μορφή αρχείου υποστηρίζεται πλήρως από το Aspose.CAD. |
