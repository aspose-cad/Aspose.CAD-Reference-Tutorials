# Εξαγωγή DWG σε PDF και ενεργοποίηση παρακολούθησης με Aspose.CAD Java

## Εισαγωγή

Η εξαγωγή DWG σε PDF διατηρώντας πλήρη διαφάνεια στη διαδικασία μετατροπής είναι ουσιώδης για τις σύγχρονες ομάδες που εστιάζουν στο CAD. Σε αυτόν τον οδηγό θα ανακαλύψετε **πώς να ενεργοποιήσετε την παρακολούθηση** στις ροές εργασίας DWG, να μετατρέψετε DXF σε PDF στην ίδια γραμμή παραγωγής και να καταγράψετε κάθε προειδοποίηση απόδοσης με μια **προσαρμοσμένη κλάση διαχείρισης σφαλμάτων Java**. Στο τέλος θα έχετε ένα έτοιμο για παραγωγή απόσπασμα που όχι μόνο παράγει PDF υψηλής πιστότητας αλλά επίσης καταγράφει διαγνωστικές πληροφορίες για έλεγχο και αντιμετώπιση προβλημάτων.

## Γρήγορες απαντήσεις
- **Τι κάνει το “enable dwg tracking java”;** Ενεργοποιεί τις κλήσεις επιστροφής απόδοσης του Aspose.CAD ώστε να μπορείτε να βλέπετε προειδοποιήσεις και σφάλματα κατά την εξαγωγή.  
- **Χρειάζομαι άδεια;** Μια δοκιμαστική έκδοση λειτουργεί για δοκιμές· απαιτείται εμπορική άδεια για χρήση σε παραγωγή.  
- **Μπορώ επίσης να μετατρέψω DXF σε PDF;** Ναι – το ίδιο αντικείμενο `PdfOptions` που χρησιμοποιείται για DWG λειτουργεί και για DXF, καλύπτοντας το σενάριο *java convert dxf pdf*.  
- **Ποια έκδοση JDK απαιτείται;** Java 8 ή νεότερη.  
- **Πού μπορώ να βρω περισσότερα παραδείγματα;** Δείτε την [Aspose.CAD Java Documentation](https://reference.aspose.com/cad/java/) παρακάτω.

## Τι είναι η εξαγωγή dwg σε pdf;

Η εξαγωγή DWG σε PDF είναι η διαδικασία μετατροπής ενός εγγενούς σχεδίου AutoCAD (DWG) σε ένα φορητό έγγραφο PDF διατηρώντας την ακρίβεια των διανυσματικών στοιχείων, τα επίπεδα και τις σημειώσεις. **Το Aspose.CAD μετατρέπει DWG σε PDF σε καθαρή Java, έτσι δεν χρειάζεστε ποτέ εγκατεστημένο AutoCAD με άδεια.** Αυτή η μετατροπή διατηρεί ακριβώς τα βάρη των γραμμών, τα στυλ κειμένου και τη γεωμετρία διάταξης, καθιστώντας το PDF κατάλληλο για ανασκόπηση από πελάτες, αρχειοθέτηση ή επεξεργασία σε επόμενα στάδια.

## Γιατί να χρησιμοποιήσετε το Aspose.CAD για Java;

## Πώς να εξάγετε DWG σε PDF;

Φορτώστε το αρχείο προέλευσης, διαμορφώστε το `PdfOptions`, συνδέστε ένα προσαρμοσμένο `CadRenderHandler` και καλέστε το `save`. Αυτή η ροή από την αρχή μέχρι το τέλος μετατρέπει DWG (ή DXF) σε PDF ενώ εκπέμπει πληροφορίες παρακολούθησης για κάθε βήμα απόδοσης, εξασφαλίζοντας ότι τυχόν προειδοποιήσεις ή σφάλματα καταγράφονται και μπορούν να αντιμετωπιστούν από προγραμματιστές ή αυτοματοποιημένες διαδικασίες.

## Εισαγωγή χώρων ονομάτων

Η διεπαφή `CadRenderHandler` λαμβάνει διαγνωστικά στοιχεία απόδοσης όπως προειδοποιήσεις και σφάλματα κατά τη μετατροπή.  
```java
import com.aspose.cad.Image;

import com.aspose.cad.imageoptions.CadRasterizationOptions;
import com.aspose.cad.imageoptions.CadRenderResult;
import com.aspose.cad.imageoptions.PdfOptions;
import com.aspose.cad.imageoptions.RenderResult;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.OutputStream;
```

## Βήμα 1: φόρτωση του αρχείου dwg/dxf  

`CadImage` αντιπροσωπεύει ένα σχέδιο CAD που έχει φορτωθεί στη μνήμη και παρέχει πρόσβαση στις σελίδες και τα επίπεδα του.  
```java
String dataDir = "Your Document Directory" + "DXFDrawings/";
Image image = Image.load(dataDir + "conic_pyramid.dxf");
```

## Βήμα 2: διαμόρφωση επιλογών εξαγωγής pdf (πώς να μετατρέψετε dxf σε pdf)

`PdfOptions` ορίζει τις ρυθμίσεις εξόδου PDF, ενώ `VectorRasterizationOptions` ελέγχει τις παραμέτρους rasterization όπως DPI και χρώμα φόντου.  
```java
OutputStream stream = new FileOutputStream(dataDir + "output_conic_pyramid.pdf");
PdfOptions pdfOptions = new PdfOptions();
CadRasterizationOptions cadRasterizationOptions = new CadRasterizationOptions();
pdfOptions.setVectorRasterizationOptions(cadRasterizationOptions);
cadRasterizationOptions.setPageWidth(800);
cadRasterizationOptions.setPageHeight(600);
```

## Βήμα 3: υλοποίηση παρακολούθησης (custom error handler java)

`ErrorHandler` επεκτείνει το `CadRenderHandler` για να συλλαμβάνει και να καταγράφει μηνύματα απόδοσης που εκδίδονται κατά τη διαδικασία μετατροπής.  
```java
cadRasterizationOptions.RenderResult = new ErrorHandler();
```

## Βήμα 4: εξαγωγή σε pdf  

Καλώντας τη μέθοδο `save` στο αντικείμενο `CadImage` γράφει το παραχθέν PDF στη συγκεκριμένη διαδρομή εξόδου.  
```java
System.out.println("Exporting to pdf format");
image.save(stream, pdfOptions);
```

## Βήμα 5: κλάση cadrenderhandler  

`CadRenderHandler` είναι η βασική κλάση κλήσης επιστροφής που λαμβάνει ένα `RenderResult` με λεπτομερή μηνύματα μετά την ολοκλήρωση της απόδοσης.  
```java
public static class ErrorHandler extends CadRasterizationOptions.CadRenderHandler {
    @Override
    public void invoke(CadRenderResult result) {
        System.out.println("Tracking results of exporting");

        if (result.isRenderComplete())
            return;

        System.out.println("Have some problems:");

        int idxError = 1;
        for (RenderResult rr : result.getFailures()) {
            System.out.printf("{0}. {1}, {2}", idxError, rr.getRenderCode(), rr.getMessage());
            idxError++;
        }
    }
}
```

## Κοινά προβλήματα και λύσεις

- **`NullPointerException` on `RenderResult`** – Βεβαιωθείτε ότι χρησιμοποιείτε Aspose.CAD 23.10 ή νεότερη· οι παλαιότερες εκδόσεις δεν διαθέτουν το API `RenderResult`.  
- **File not found** – Ελέγξτε ξανά ότι το `dataDir` δείχνει στον σωστό φάκελο και ότι το όνομα αρχείου ταιριάζει ακριβώς με πεζά‑κεφαλαία.  
- **Missing tracking output** – Επαληθεύστε ότι η παρουσία `ErrorHandler` έχει ανατεθεί σωστά στο `cadRasterizationOptions.setRenderHandler(new ErrorHandler())`.
