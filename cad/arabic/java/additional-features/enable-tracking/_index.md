# تصدير DWG إلى PDF وتفعيل التتبع باستخدام Aspose.CAD Java

## مقدمة

تصدير DWG إلى PDF مع الحفاظ على رؤية كاملة لعملية التحويل أمر أساسي للفرق التي تركز على CAD في العصر الحديث. في هذا الدليل ستكتشف **كيفية تفعيل التتبع** في سير عمل DWG، وتحويل DXF إلى PDF في نفس الخطوة، والتقاط كل تحذير أثناء العرض باستخدام فئة **معالج أخطاء مخصص Java**. في النهاية ستحصل على مقتطف جاهز للإنتاج لا ينتج فقط ملفات PDF عالية الدقة بل يسجل أيضاً معلومات تشخيصية للتدقيق وحل المشكلات.

## إجابات سريعة
- **ماذا يفعل “enable dwg tracking java”؟** يقوم بتنشيط ردود استدعاء العرض في Aspose.CAD حتى تتمكن من رؤية التحذيرات والأخطاء أثناء التصدير.  
- **هل أحتاج إلى ترخيص؟** النسخة التجريبية تعمل للاختبار؛ يلزم الحصول على ترخيص تجاري للاستخدام الإنتاجي.  
- **هل يمكنني أيضاً تحويل DXF إلى PDF؟** نعم – كائن `PdfOptions` نفسه المستخدم لـ DWG يعمل مع DXF، مما يغطي سيناريو *java convert dxf pdf*.  
- **ما نسخة JDK المطلوبة؟** Java 8 أو أعلى.  
- **أين يمكنني العثور على المزيد من الأمثلة؟** راجع [توثيق Aspose.CAD Java](https://reference.aspose.com/cad/java/) أدناه.

## ما هو تصدير DWG إلى PDF؟

تصدير DWG إلى PDF هو عملية تحويل رسم AutoCAD الأصلي (DWG) إلى مستند PDF محمول مع الحفاظ على دقة المتجهات، الطبقات، والتعليقات التوضيحية. **يقوم Aspose.CAD بتحويل DWG إلى PDF باستخدام Java النقي، لذا لا تحتاج أبداً إلى تثبيت AutoCAD مرخص.** تحتفظ هذه العملية بأوزان الخطوط، أنماط النص، وهندسة التخطيط بدقة، مما يجعل PDF مناسباً لمراجعة العملاء، الأرشفة، أو المعالجة اللاحقة.

## لماذا نستخدم Aspose.CAD للـ Java؟

يوفر Aspose.CAD للـ Java حلاً شاملاً ومكتوباً بالكامل بـ Java لتحويل CAD، يدعم أكثر من 50 صيغة، يقدم أداءً عالياً، ويوفر تتبعاً مدمجاً عبر ردود استدعاء العرض. لا يتطلب أي تبعيات خارجية ويمكن دمجه في خطوط أنابيب الخادم. تشمل المكتبة أيضاً معالجة فعّالة للذاكرة، مما يسمح بتحويل ملفات تصل إلى 500 صفحة دون تحميل المستند بالكامل في الذاكرة.

## المتطلبات المسبقة

- **Java Development Kit (JDK)** 8 أو أحدث مثبت على جهازك.  
- **Aspose.CAD للـ Java** تم تنزيله من [رابط التحميل الرسمي](https://releases.aspose.com/cad/java/).

- مجلد يحتوي على ملفات DWG/DXF التي ترغب في تحويلها.  

## كيفية تصدير DWG إلى PDF؟

حمّل ملف المصدر، اضبط `PdfOptions`، أرفق `CadRenderHandler` مخصص، ثم استدعِ `save`. هذه العملية المتكاملة تحول DWG (أو DXF) إلى PDF مع إصدار معلومات تتبع لكل خطوة عرض، مما يضمن التقاط أي تحذيرات أو أخطاء يمكن للمطورين أو العمليات الآلية التعامل معها.

## استيراد مساحات الأسماء

واجهة `CadRenderHandler` تستقبل تشخيصات العرض مثل التحذيرات والأخطاء أثناء التحويل.  
```java
import com.aspose.cad.Image;

import com.aspose.cad.imageoptions.CadRasterizationOptions;
import com.aspose.cad.imageoptions.CadRenderResult;
import com.aspose.cad.imageoptions.PdfOptions;
import com.aspose.cad.imageoptions.RenderResult;
import java.io.FileNotFoundException;
import java.io.FileOutputStream;
import java.io.OutputStream;
```

## الخطوة 1: تحميل ملف dwg/dxf  

`CadImage` تمثل رسم CAD محملاً في الذاكرة وتوفر الوصول إلى صفحاته وطبقاتِه.  
```java
String dataDir = "Your Document Directory" + "DXFDrawings/";
Image image = Image.load(dataDir + "conic_pyramid.dxf");
```

## الخطوة 2: تكوين خيارات تصدير PDF (كيفية تحويل dxf إلى pdf)

`PdfOptions` تُعرّف إعدادات إخراج PDF، بينما `VectorRasterizationOptions` تتحكم في معلمات التحويل إلى نقطية مثل DPI ولون الخلفية.  
```java
OutputStream stream = new FileOutputStream(dataDir + "output_conic_pyramid.pdf");
PdfOptions pdfOptions = new PdfOptions();
CadRasterizationOptions cadRasterizationOptions = new CadRasterizationOptions();
pdfOptions.setVectorRasterizationOptions(cadRasterizationOptions);
cadRasterizationOptions.setPageWidth(800);
cadRasterizationOptions.setPageHeight(600);
```

## الخطوة 3: تنفيذ التتبع (معالج أخطاء مخصص java)

`ErrorHandler` يمد `CadRenderHandler` لالتقاط وتسجيل رسائل العرض التي تُصدر أثناء عملية التحويل.  
```java
cadRasterizationOptions.RenderResult = new ErrorHandler();
```

## الخطوة 4: تصدير إلى PDF  

استدعاء طريقة `save` على كائن `CadImage` يكتب ملف PDF المُعرض إلى المسار المحدد.  
```java
System.out.println("Exporting to pdf format");
image.save(stream, pdfOptions);
```

## الخطوة 5: فئة CadRenderHandler  

`CadRenderHandler` هي فئة رد الاتصال الأساسية التي تستقبل `RenderResult` يحتوي على رسائل مفصلة بعد اكتمال العرض.  
```java
public static class ErrorHandler extends CadRasterizationOptions.CadRenderHandler {
    @Override
    public void invoke(CadRenderResult result) {
        System.out.println("Tracking results of exporting");

        if (result.isRenderComplete())
            return;

        System.out.println("Have some problems:");

        int idxError = 1;
        for (RenderResult rr : result.getFailures()) {
            System.out.printf("{0}. {1}, {2}", idxError, rr.getRenderCode(), rr.getMessage());
            idxError++;
        }
    }
}
```

## لماذا هذا مهم

تفعيل التتبع يخلق سجل تدقيق يفي بمتطلبات الامتثال في القطاعات المنظمة مثل الهندسة المعمارية، الهندسة، والبناء. كما يتيح معالج الأخطاء المخصص دمج فحوصات صحة تحويل CAD في خطوط CI/CD، مع الإشارة تلقائياً إلى الملفات التي تحتاج إلى مراجعة يدوية.

## المشكلات الشائعة والحلول

- **`NullPointerException` على `RenderResult`** – تأكد من أنك تستخدم Aspose.CAD 23.10 أو أحدث؛ الإصدارات السابقة لا تتضمن واجهة `RenderResult`.  
- **الملف غير موجود** – تحقق من أن `dataDir` يشير إلى المجلد الصحيح وأن اسم الملف يطابق الحالة الحساسة للأحرف.  
- **عدم ظهور مخرجات التتبع** – تأكد من أن مثيل `ErrorHandler` تم تعيينه بشكل صحيح إلى `cadRasterizationOptions.setRenderHandler(new ErrorHandler())`.
