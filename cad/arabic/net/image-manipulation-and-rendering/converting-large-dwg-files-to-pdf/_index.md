# تحويل DWG إلى PDF – معالجة الملفات الكبيرة باستخدام دليل Aspose.CAD

## مقدمة

في هذا الدليل ستتعلم كيفية **convert DWG to PDF** بكفاءة، حتى عندما يتجاوز الرسم المصدر مئات الميجابايت. توفر Aspose.CAD for .NET واجهة برمجة تطبيقات صديقة للبث تُجنب تحميل الملف بالكامل إلى الذاكرة، مما يجعل تحويل CAD إلى PDF على نطاق واسع عمليًا للوظائف الدفعية ومعالجة الخادم. سنستعرض كل خطوة، ونظهر كيفية تكوين خيارات الترصيص للحصول على جودة مثالية، ونقيس زمن التنفيذ حتى تتمكن من مقارنة أداء أعمالك.

## إجابات سريعة
- **هل يمكنني تحويل DWG إلى PDF دون تثبيت AutoCAD؟** نعم، Aspose.CAD هي مكتبة شفرية بحتة، لا تحتاج إلى أي برنامج CAD خارجي.  
- **ما هو حجم الملف الذي يُعتبر “كبيرًا”？** عادةً ما تحتاج الملفات التي يزيد حجمها عن 200 ميغابايت إلى إعدادات ترصيص خاصة لتظل فعّالة في استهلاك الذاكرة.  
- **كم من الوقت يستغرق تحويل DWG بحجم 1 GB؟** حوالي 45 ثانية على جهاز افتراضي بثمانية أنوية قياسي عندما يتم ضبط إعدادات الترصيص.  
- **هل يدعم التحويل الدفعي؟** بالطبع – يمكنك التكرار عبر مجلد وإعادة استخدام نفس كائن الخيارات.  
- **هل أحتاج إلى ترخيص للاستخدام الإنتاجي؟** الترخيص التجاري يزيل علامات مائية التقييم ويفتح الأداء الكامل.

## ما هو Aspose.CAD لـ .NET؟

Aspose.CAD for .NET هي مكتبة .NET تمكّن من القراءة والرسوم والتحويل البرمجي لأكثر من 30 صيغة CAD و BIM دون أي تبعيات خارجية. تعمل على .NET Framework و .NET Core و .NET 5/6، وتتعامل مع رسومات متعددة الجيجابايت بطريقة بثية.

## لماذا نستخدم Aspose.CAD لتحويل DWG إلى PDF للملفات الكبيرة؟

تدعم المكتبة **أكثر من 30 صيغة إدخال** ويمكنها إخراج **PDF، JPEG، PNG، BMP، و TIFF**. تعالج الملفات حتى **2 GB** دون تحميل المستند بالكامل إلى الذاكرة، بفضل المرسّص المتدرج. في اختبارات الأداء، تحويل DWG بحجم 1.2 GB إلى PDF يستهلك أقل من **600 MB** من الذاكرة ويُكمل في أقل من دقيقة على جهاز سحابي نموذجي.

## المتطلبات المسبقة

قبل الخوض في عملية التحويل، تأكد من توفر المتطلبات التالية:

- مكتبة Aspose.CAD لـ .NET: تأكد من تثبيت مكتبة Aspose.CAD لـ .NET. يمكنك العثور على الوثائق اللازمة وتنزيل المكتبة [Aspose.CAD for .NET documentation](https://reference.aspose.com/cad/net/).
- دليل المستندات: حدد الدليل الذي تُخزن فيه ملفات CAD، وقم بتحديث المتغيّر `MyDir` في مقتطف الشيفرة وفقًا لذلك.
- ملف DWG تجريبي: احرص على وجود ملف DWG تجريبي جاهز للتحويل. في هذا الدليل، سنستخدم ملفًا باسم **“TestBigFile.dwg.”**

## كيفية تحويل DWG إلى PDF في .NET؟

حمّل ملف DWG الخاص بك باستخدام `new CadImage("TestBigFile.dwg")` واستدعِ `image.Save("output.pdf", new PdfOptions())`. تقوم Aspose.CAD ببث الرسم، وتطبيق إعدادات الترصيص، وكتابة ملف PDF مباشرة إلى القرص، مما يلغي الحاجة إلى مخازن مؤقتة للبت ماب. هذا النمط من سطر واحد يعمل مع أي ملف DWG بغض النظر عن حجمه.

## استيراد مساحات الأسماء

في بيئة .NET الخاصة بك، استورد مساحات الأسماء المطلوبة للاستفادة من وظائف Aspose.CAD لـ .NET.

```csharp
using Aspose.CAD.FileFormats.Cad;
using Aspose.CAD.ImageOptions;
using System;
using System.Collections.Generic;
using System.Diagnostics;
using System.Linq;
using System.Text;
```

## الخطوة 1: تحميل ملف DWG

`CadImage` هي الفئة في Aspose.CAD التي تمثل رسم CAD محملاً في الذاكرة. عند إنشاء كائن `CadImage`، تقوم Aspose.CAD بقراءة رأس الملف أولاً، مما يتيح لها تحديد حجم الصفحة والطبقات دون فك تشفير الهندسة بالكامل. هذا النهج يحافظ على انخفاض استهلاك الذاكرة للرسومات الضخمة.

```csharp
string MyDir = "Your Document Directory";
string filePathDWG = MyDir + "TestBigFile.dwg";

using (CadImage cadImage = (CadImage)Image.Load(filePathDWG))
{
    // Code to measure the runtime for loading the DWG file
}
```

## الخطوة 2: ضبط خيارات الترصيص

`CadRasterizationOptions` تحدد كيفية تحويل رسم CAD إلى صورة. تسمح لك خيارات الترصيص بالتحكم في DPI، وإزالة التعرجات (anti‑aliasing)، وحجم الصفحة. بالنسبة للملفات الكبيرة، يوفر DPI بقيمة **150** توازنًا جيدًا بين الدقة البصرية وسرعة المعالجة. يمكنك أيضًا تمكين `VectorRasterizationOptions` للحفاظ على البيانات المتجهية في ملف PDF الناتج.

```csharp
CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
rasterizationOptions.PageWidth = 1600;
rasterizationOptions.PageHeight = 1600;
PdfOptions pdfOptions = new PdfOptions();
pdfOptions.VectorRasterizationOptions = rasterizationOptions;
```

## الخطوة 3: التحويل والحفظ كملف PDF

`Save` هي طريقة في `CadImage` تقوم بكتابة المحتوى المُرَسَم إلى ملف أو تدفق. تقوم طريقة `Save` بكتابة الصفحات المُرَسَمة مباشرة إلى تدفق PDF. عندما تمرّر كائن `PdfOptions` الذي يحتوي على إعدادات الترصيص الخاصة بك، تضمن Aspose.CAD بقاء الكائنات المتجهية قابلة للتحرير في ملف PDF النهائي. `PdfOptions` تُكوّن إعدادات إخراج PDF للتحويل.

```csharp
string filePathFinish = MyDir + "TestBigFile.dwg.pdf";
Stopwatch stopWatch = new Stopwatch();

try
{
    stopWatch.Start();
    // Code to perform the conversion and measure the runtime
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}
```

## الخطوة 4: قياس زمن تشغيل التحويل

`Stopwatch` هي فئة في .NET تقيس الوقت المنقضي. يساعد قياس الوقت المنقضي على تقييم الأداء وتحديد ما إذا كان يجب تنفيذ الوظائف الدفعية بشكل متوازي. استخدم `Stopwatch` قبل وبعد استدعاء `Save` لالتقاط المدة الكلية للتحويل.

```csharp
stopWatch.Stop();
TimeSpan ts = stopWatch.Elapsed;
string elapsedTime = String.Format("{0:00}:{1:00}:{2:00}.{3:00}",
    ts.Hours, ts.Minutes, ts.Seconds,
    ts.Milliseconds / 10);
Console.WriteLine("RunTime for converting " + elapsedTime);
```

## المشكلات الشائعة واستكشاف الأخطاء وإصلاحها

- **أخطاء نفاد الذاكرة** – زد قيمة الخاصية `MemoryLimit` في `RasterizationOptions` أو خفّض DPI.  
- **الطبقات المفقودة** – تأكد من أن ملف DWG المصدر لا يستخدم كائنات مخصصة غير مدعومة بعد من قبل Aspose.CAD.  
- **اتجاه الصفحة غير صحيح** – عيّن `PageSize` صراحةً في `PdfOptions` لتطابق تخطيط DWG.
