## استيراد مساحات الأسماء

فئة `Image` هي الفئة الأساسية التي تمثل رسم CAD في الذاكرة. `CadRasterizationOptions` تحدد كيفية تحويل رسم CAD إلى مخرجات متجهة. فئة `PdfOptions` تحدد إعدادات الإخراج لملفات PDF.

``` 
using Aspose.CAD;
using Aspose.CAD.ImageOptions;
```

توفر هذه المساحات الوظائف الأساسية لتحميل، رستر، وحفظ رسومات CAD.

## كيفية تحويل IGES إلى PDF باستخدام Aspose.CAD؟

قم بتحميل ملف IGES باستخدام `Image.Load` واستدعِ فورًا `Save` مع خيار رستر PDF – هذه هي عملية التحويل الكاملة في سطرين. تتولى المكتبة عملية الرندر المتجه، تضمين الخطوط، وتوسيع الصفحات تلقائيًا، لتحصل على نسخة PDF مطابقة للنموذج الأصلي لـ IGES.

### الخطوة 1: إعداد مشروعك

أنشئ مشروع وحدة تحكم .NET جديد أو مكتبة فئة، أو افتح مشروعًا موجودًا ترغب في إضافة ميزة التحويل إليه.

### الخطوة 2: إضافة مرجع Aspose.CAD

أضف ملف Aspose.CAD DLL الذي تم تنزيله إلى مراجع مشروعك. في Visual Studio، انقر بزر الماوس الأيمن على **References → Add Reference → Browse** واختر ملف DLL.

### الخطوة 3: تهيئة المسار

حدد المجلد الذي يحتوي على ملف IGES وموقع الإخراج.

``` 
string sourceDir = @"C:\CAD\Source";
string outputDir = @"C:\CAD\Output";
string igesFile = Path.Combine(sourceDir, "sample.iges");
string pdfFile = Path.Combine(outputDir, "sample.pdf");
```

### الخطوة 4: تحميل صورة CAD

`Image.Load` يقرأ ملف IGES ويخلق تمثيلًا في الذاكرة.

``` 
Image cadImage = Image.Load(igesFile);
```

فئة `Image` هي نقطة الدخول الأساسية لـ Aspose.CAD لأي تنسيق CAD.

### الخطوة 5: تكوين خيارات الرستر

`PdfOptions` (المشتقة من `CadRasterizationOptions`) تتيح لك ضبط حجم الصفحة، الدقة، وعلامات الحفاظ على المتجهات.

``` 
PdfOptions pdfOptions = new PdfOptions
{
    VectorRasterizationOptions = new CadRasterizationOptions
    {
        PageWidth = 842,      // A4 width in points
        PageHeight = 595,     // A4 height in points
        Resolution = 300      // 300 DPI for high‑quality output
    }
};
```

فئة `PdfOptions` تحدد كيفية رستر رسم CAD وحفظه كملف PDF.

### الخطوة 6: حفظ كملف PDF

أخيرًا، اكتب ملف PDF إلى القرص.

``` 
cadImage.Save(pdfFile, pdfOptions);
```

مع هذه الخطوات الست البسيطة، تكون قد نجحت في **convert iges to pdf** باستخدام Aspose.CAD لـ .NET.

## المشكلات الشائعة والنصائح

- **الملفات الكبيرة:** زد `Resolution` فقط إذا كنت تحتاج إلى تفاصيل أدق؛ DPI أعلى يستهلك المزيد من الذاكرة.  
- **الخطوط المفقودة:** تأكد من تثبيت أي خطوط مخصصة مستخدمة في ملف IGES على الخادم؛ وإلا سيتم استبدالها.  
- **التحويل الجماعي:** ضع منطق التحميل‑الحفظ داخل حلقة `foreach` لمعالجة ملفات IGES متعددة تلقائيًا.
