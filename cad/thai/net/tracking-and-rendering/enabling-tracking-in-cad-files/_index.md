# วิธีแปลงไฟล์ CAD เป็น PDF และเปิดใช้งานการติดตาม

## บทนำ

การแปลงไฟล์ CAD เป็น PDF พร้อมคงข้อมูลการติดตามอย่างครบถ้วนเป็นสิ่งสำคัญสำหรับกระบวนการวิศวกรรมที่ควบคุมคุณภาพ ในบทเรียนนี้คุณจะได้เรียนรู้วิธี **แปลงไฟล์ CAD เป็น PDF** และเปิดใช้งานการติดตามด้วย Aspose.CAD for .NET เพื่อให้ได้การเรนเดอร์ที่แม่นยำและรายงานข้อผิดพลาดอย่างละเอียดตลอดกระบวนการส่งออก

## คำตอบอย่างรวดเร็ว
- **การติดตามให้ข้อมูลอะไรบ้าง?** มันบันทึกคำเตือนและข้อผิดพลาดในการเรนเดอร์ ช่วยให้คุณระบุเอนทิตีที่เป็นปัญหาในไฟล์ CAD ต้นฉบับได้  
- **รูปแบบไฟล์ที่รองรับคืออะไร?** Aspose.CAD รองรับรูปแบบ CAD อินพุตกว่า 30 รูปแบบและสามารถส่งออกเป็น PDF, SVG, PNG และอื่น ๆ  
- **ต้องการไลเซนส์หรือไม่?** ไลเซนส์ชั่วคราวใช้สำหรับการประเมินผลได้; ไลเซนส์เต็มจำเป็นสำหรับการใช้งานในผลิตภัณฑ์  
- **เวอร์ชัน .NET ที่เข้ากันได้คืออะไร?** .NET Framework 4.5+, .NET Core 3.1+, .NET 5/6/7 รองรับเต็มที่  
- **การแปลงใช้เวลานานเท่าไหร่?** ไฟล์ DXF ปกติที่มีขนาดต่ำกว่า 5 MB แปลงได้ภายในไม่กี่วินาทีบนฮาร์ดแวร์มาตรฐาน

## การแปลงไฟล์ CAD เป็น PDF คืออะไร?
**การแปลงไฟล์ CAD เป็น PDF** คือกระบวนการเรนเดอร์ภาพวาด CAD (เช่น DXF หรือ DWG) เป็นเอกสาร PDF พร้อมคงความแม่นยำของเวกเตอร์และเมตาดาต้าการติดตามแบบเลือกได้ การดำเนินการนี้ทำให้คุณสามารถแชร์ตัวแทนที่อ่าน‑อย่าง‑เดียวของการออกแบบกับผู้มีส่วนได้ส่วนเสียที่อาจไม่มีซอฟต์แวร์ CAD

## ทำไมต้องเปิดใช้งานการติดตามเมื่อแปลงไฟล์ CAD เป็น PDF?
การเปิดใช้งานการติดตามจะบันทึกการวินิจฉัยการเรนเดอร์อย่างละเอียด—เช่น ฟอนต์ที่หายไป, เอนทิตีที่ไม่รองรับ, หรือข้อผิดพลาดของเรขาคณิต—เพื่อให้คุณแก้ไขปัญหาก่อนการแจกจ่ายขั้นสุดท้าย Aspose.CAD บันทึกคำเตือนได้สูงสุด 1,000 รายการต่อการแปลงและรายงานในล็อก `PdfExportOptions` ลดการทำงานซ้ำได้ถึง 40 % ในโครงการวิศวกรรมขนาดใหญ่

## ข้อกำหนดเบื้องต้น

ก่อนเริ่มทำตามขั้นตอน ให้ตรวจสอบว่าคุณมีสิ่งต่อไปนี้:

- **Aspose.CAD for .NET** – ดาวน์โหลดไลบรารีล่าสุดจากหน้าเว็บไซต์อย่างเป็นทางการ [หน้าดาวน์โหลด Aspose.CAD for .NET](https://releases.aspose.com/cad/net/)  
- **เอกสาร CAD** – สำหรับคู่มือนี้เราจะใช้ `conic_pyramid.dxf`  
- **ไดเรกทอรีที่สามารถเขียนได้** – แทนที่ข้อความตัวอย่าง “Your Document Directory” ในโค้ดด้วยพาธที่เป็นจริงบนเครื่องของคุณ  

เมื่อมีสิ่งเหล่านี้พร้อม คุณจะสามารถทำตามขั้นตอนได้โดยไม่สะดุด

## นำเข้า namespace

คำสั่ง `using` ด้านล่างนี้จะนำเข้า namespace ของ Aspose.CAD ที่จำเป็นเข้าสู่สโคป  
```csharp
using Aspose.CAD.ImageOptions;
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Text;
```

## ขั้นตอนที่ 1: โหลดภาพ CAD

การโหลดไฟล์ต้นฉบับจะสร้างการแสดงผลในหน่วยความจำที่ Aspose.CAD สามารถจัดการได้ วัตถุ `Image` จะตรวจจับรูปแบบไฟล์โดยอัตโนมัติและเตรียมพร้อมสำหรับการส่งออก  
```csharp
string MyDir = "Your Document Directory";
using (Image image = Image.Load(MyDir + "conic_pyramid.dxf"))
{
    // Code for the next steps will be added here
}
```

## ขั้นตอนที่ 2: ตั้งค่าตัวเลือกการส่งออก PDF

`PdfExportOptions` ให้คุณปรับแต่งผลลัพธ์ PDF รวมถึงขนาดหน้า, ความละเอียด, และการตั้งค่าการติดตาม โดยการกำหนดคุณสมบัติ `TrackWarnings` คุณจะเปิดใช้งานการบันทึกรายละเอียดของปัญหาการเรนเดอร์ทั้งหมด  
```csharp
using (FileStream stream = new FileStream(MyDir + "output_conic_pyramid.pdf", FileMode.Create))
{
    PdfOptions pdfOptions = new PdfOptions();
    CadRasterizationOptions cadRasterizationOptions = new CadRasterizationOptions();
    pdfOptions.VectorRasterizationOptions = cadRasterizationOptions;
    cadRasterizationOptions.PageWidth = 800;
    cadRasterizationOptions.PageHeight = 600;
```

## ขั้นตอนที่ 3: ใช้งานการติดตาม

เมื่อเปิดใช้งานการติดตาม Aspose.CAD จะเขียนล็อกคำเตือนไปยังอ็อบเจ็กต์ `PdfExportOptions` หลังจากการแปลงคุณสามารถตรวจสอบ `options.Warnings` เพื่อดูรายการข้อความที่บันทึกทั้งหมด  
```csharp
    int idxError = 1;
    cadRasterizationOptions.RenderResult += new CadRasterizationOptions.CadRenderHandler(
        delegate (CadRenderResult result)
        {
            Console.WriteLine("Tracking results of exporting");
            if (result.IsRenderComplete)
                return;
            Console.WriteLine("Have some problems:");
            foreach (RenderResult rr in result.Failures)
                Console.WriteLine(string.Format("{0}. {1}, {2}", idxError++, rr.RenderCode.ToString(), rr.Message));
        });
```

## ขั้นตอนที่ 4: บันทึกเป็นรูปแบบ PDF

สุดท้ายเรียกเมธอด `Save` ของอินสแตนซ์ `Image` พร้อมส่งผ่าน `PdfExportOptions` ที่กำหนดไว้ ไฟล์ PDF ที่ได้จะมีทั้งการเรนเดอร์ภาพและเมตาดาต้าการติดตามที่ฝังอยู่  
```csharp
    Console.WriteLine("Exporting to pdf format");
    image.Save(stream, pdfOptions);
}
```

## ปัญหาที่พบบ่อยและวิธีแก้

- **ฟอนต์หาย** – ตรวจสอบให้แน่ใจว่าฟอนต์ TrueType ที่จำเป็นได้ถูกติดตั้งบนเซิร์ฟเวอร์หรือระบุโฟลเดอร์ฟอนต์แบบกำหนดเองผ่าน `options.FontsPath`  
- **เอนทิตีที่ไม่รองรับ** – ตรวจสอบล็อกคำเตือน; เอนทิตีที่ไม่สามารถเรนเดอร์ได้จะถูกแสดงพร้อมเลเยอร์และ ID ของอ็อบเจ็กต์  
- **ไฟล์ขนาดใหญ่ (> 2 GB)** – ใช้คอนสตรัคเตอร์ `LoadOptions` พร้อม `LoadMode.Streaming` เพื่อหลีกเลี่ยงการโหลดไฟล์ทั้งหมดเข้าสู่หน่วยความจำ

A: ปัญหาเช่น ฟอนต์หาย, ประเภทเส้นที่ไม่รองรับ, หรือเอนทิตีเสียหายอาจเกิดขึ้น ล็อกการติดตามจะให้รายละเอียดที่แม่นยำสำหรับแต่ละคำเตือน

### Q4: มีฟอรั่มชุมชนสำหรับการสนับสนุน Aspose.CAD หรือไม่?

### Q5: ฉันสามารถปรับแต่งข้อความข้อผิดพลาดของการติดตามได้หรือไม่?
