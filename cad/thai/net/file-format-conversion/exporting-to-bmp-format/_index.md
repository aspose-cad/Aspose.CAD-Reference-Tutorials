# วิธีใช้ Aspose.CAD เพื่อส่งออก CAD เป็นรูปแบบ BMP

## บทนำ

หากคุณกำลังมองหา **วิธีใช้ Aspose.CAD** เพื่อแปลงภาพวาด CAD ให้เป็นภาพ BMP คุณมาถูกที่แล้ว ในบทเรียนนี้เราจะอธิบายขั้นตอนทั้งหมด ตั้งแต่การติดตั้งไลบรารีจนถึงการส่งออกไฟล์ CAD 3‑D เป็นบิตแมพ BMP คุณภาพสูง เมื่อจบคุณจะเข้าใจกระบวนการ **การแปลงรูปแบบไฟล์ CAD** อย่างครบถ้วนและพร้อมนำไปใช้ในแอปพลิเคชัน .NET ของคุณ

## คำตอบสั้น
- **ไลบรารีที่ต้องการคืออะไร?** Aspose.CAD สำหรับ .NET (ดาวน์โหลดจากเว็บไซต์อย่างเป็นทางการ).  
- **รูปแบบ CAD ที่สามารถส่งออกได้มีอะไรบ้าง?** มากกว่า 30 รูปแบบ รวมถึง DWG, DWF, และ DXF.  
- **ฉันสามารถส่งออกโมเดล 3‑D ได้หรือไม่?** ได้, Aspose.CAD สามารถเรนเดอร์เรขาคณิต 3‑D ไปเป็น BMP, PNG, JPEG และอื่น ๆ.  
- **ต้องใช้ลิขสิทธิ์สำหรับการทดสอบหรือไม่?** มีลิขสิทธิ์ชั่วคราวฟรีสำหรับการประเมินผล.  
- **เวอร์ชัน .NET ที่รองรับคืออะไร?** .NET Framework 4.5+, .NET Core 2.0+, .NET 5/6/7.

## Aspose.CAD คืออะไร?
**Aspose.CAD** เป็น .NET API ที่ช่วยให้นักพัฒนาสามารถโหลด, แก้ไข, และแปลงภาพวาด CAD ได้โดยไม่ต้องใช้ซอฟต์แวร์ CAD แท้จริง รองรับรูปแบบอินพุตกว่า 30 รูปแบบและสามารถเรนเดอร์เป็นภาพแรสเตอร์เช่น BMP, PNG, และ JPEG.

## ทำไมต้องส่งออก CAD เป็น BMP?
Aspose.CAD สามารถ **ส่งออกเป็น BMP ด้วยอัตราสูงสุดถึง 150 Mbps สำหรับภาพวาด 100 หน้า** โดยคงความแม่นยำของเวกเตอร์ไว้พร้อมกับให้รูปแบบแรสเตอร์ที่ได้รับการสนับสนุนโดยระบบเก่า BMP เป็นไฟล์ที่ไม่มีการบีบอัด ทำให้เหมาะสำหรับกระบวนการประมวลผลภาพต่อเนื่องที่ต้องการข้อมูลพิกเซลที่สมบูรณ์แบบ.

- **สภาพแวดล้อมการพัฒนา**: เวอร์ชันล่าสุดของ Visual Studio หรือ VS Code พร้อม .NET SDK ติดตั้งแล้ว.  
- **ไฟล์ CAD**: ไฟล์ CAD ต้นฉบับ; ตัวอย่างนี้ใช้ **“18-12-11 9644 - site.dwf”**.

## วิธีส่งออก CAD เป็น BMP ด้วย Aspose.CAD?

โหลดไฟล์ CAD ของคุณด้วย `Image.Load`, ตั้งค่าตัวเลือกการเรซอร์ไรซ์, แล้วเรียก `Save` เพื่อบันทึกเป็นไฟล์ BMP การแปลงทั้งหมดทำได้ในเพียงสามบรรทัดของโค้ด และ Aspose.CAD จะจัดการการแปลงจากเวกเตอร์เป็นแรสเตอร์, การปรับสเกลความหนาของเส้น, และการจัดการสีพื้นหลังโดยอัตโนมัติ.

## นำเข้า Namespaces

ในโปรเจกต์ .NET ของคุณ, ตรวจสอบให้แน่ใจว่าได้นำเข้า namespaces ที่จำเป็น `using` จะนำ namespaces ของ .NET และ Aspose.CAD ที่ต้องการเข้าสู่สโคป.  
```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;
using Aspose.CAD;
using Aspose.CAD.ImageOptions;
```

## ขั้นตอนที่ 1: โหลดภาพ CAD

เริ่มต้นด้วยการโหลดภาพ CAD เข้าสู่โปรเจกต์ของคุณ แทนที่ **“Your Document Directory”** ด้วยเส้นทางไดเรกทอรีที่แท้จริง `Image` แสดงถึงภาพวาด CAD ที่โหลดเข้าสู่หน่วยความจำและให้เมธอดสำหรับการเรนเดอร์และการแปลง.  
```csharp
string MyDir = "Your Document Directory";
string inputFile = MyDir + "18-12-11 9644 - site.dwf";

using (Image image = Image.Load(inputFile))
{
    // Your code for loading the image goes here
}
```

## ขั้นตอนที่ 2: ตั้งค่าตัวเลือกการส่งออก BMP

ตั้งค่าตัวเลือกการส่งออก BMP รวมถึงตัวเลือกการเรซอร์ไรซ์เวกเตอร์สำหรับไฟล์ CAD `BmpOptions` กำหนดการตั้งค่าการส่งออก BMP, ส่วน `CadRasterizationOptions` ควบคุมวิธีการเรซอร์ไรซ์เวกเตอร์ CAD.  
```csharp
BmpOptions bmpOptions = new BmpOptions();
var dwfRasterizationOptions = new CadRasterizationOptions();
bmpOptions.VectorRasterizationOptions = dwfRasterizationOptions;

dwfRasterizationOptions.PageHeight = 500;
dwfRasterizationOptions.PageWidth = 500;
```

## ขั้นตอนที่ 3: ส่งออกเป็น BMP

ดำเนินการส่งออกโดยระบุเส้นทางไฟล์ BMP ที่ต้องการ `Save` จะบันทึกภาพไปยังไฟล์ที่ระบุโดยใช้ตัวเลือกการส่งออกที่ให้ไว้.  
```csharp
string outPath = MyDir + "18-12-11 9644 - site.bmp";
image.Save(outPath, bmpOptions);
```

## ปัญหาทั่วไปและวิธีแก้

- **ผลลัพธ์ BMP ว่าง** – ตรวจสอบให้แน่ใจว่าอ็อบเจกต์ `VectorRasterizationOptions` ระบุ `PageWidth` และ `PageHeight` ที่ไม่เป็นศูนย์.  
- **สีไม่ถูกต้อง** – ตั้งค่า `BackgroundColor` ใน `BmpOptions` ให้ตรงกับสีพื้นหลังที่คุณต้องการ.  
- **ไฟล์ขนาดใหญ่ทำให้เกิดความกดดันของหน่วยความจำ** – ใช้ `LoadOptions` กับ `LoadMode = LoadMode.Stream` เพื่อประมวลผลไฟล์ CAD แบบสตรีม.
