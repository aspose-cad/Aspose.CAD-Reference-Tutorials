## ฉันจะแปลง DWF เป็น PDF ด้วย Aspose.CAD อย่างไร?
โหลดไฟล์ DWF ต้นฉบับโดยใช้ `Image.Load`, กำหนดค่าตัวเลือกการเรซอร์ไรซ์, และเรียก `Save` ด้วยรูปแบบ PDF – นั่นคือการแปลงทั้งหมดในสามขั้นตอนที่ง่ายดาย ไลบรารีจัดการกราฟิกเวกเตอร์, เลเยอร์, และเมตาดาต้าโดยอัตโนมัติ ทำให้ PDF ที่ได้ดูเหมือนกับการออกแบบต้นฉบับอย่างสมบูรณ์.

## นำเข้า Namespaces

Namespaces ต่อไปนี้ให้การเข้าถึงฟังก์ชันหลักของ Aspose.CAD และตัวเลือก PDF.

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;
using Aspose.CAD;
using Aspose.CAD.ImageOptions;
```

## ขั้นตอนที่ 1: โหลดไฟล์ DWF

คลาส `Image` แทนภาพ CAD และให้เมธอดสำหรับโหลดและจัดการภาพนั้น.

```csharp
string MyDir = "Your Document Directory";
string fileName = MyDir + "18-12-11 9644 - site.dwf";

using (Image image = Image.Load(fileName))
{
    // Your code here...
}
```

## ขั้นตอนที่ 2: กำหนดค่าตัวเลือกการเรซอร์ไรซ์

`CadRasterizationOptions` กำหนดวิธีการเรซอร์ไรซ์ของภาพวาด CAD รวมถึงขนาดหน้าและความละเอียด.

```csharp
CadRasterizationOptions dwfRasterizationOptions = new CadRasterizationOptions();
dwfRasterizationOptions.PageHeight = 500;
dwfRasterizationOptions.PageWidth = 500;
```

## ขั้นตอนที่ 3: กำหนดตัวเลือก PDF

`PdfOptions` ระบุการตั้งค่าการส่งออก PDF สำหรับกระบวนการแปลง.

```csharp
PdfOptions pdfOptions = new PdfOptions();
pdfOptions.VectorRasterizationOptions = dwfRasterizationOptions;
```

## ขั้นตอนที่ 4: ส่งออกเป็น PDF

เมธอด `Save` จะเขียนภาพที่โหลดแล้วไปยังรูปแบบและเส้นทางที่ระบุ.

```csharp
string outPath = MyDir + "18-12-11 9644 - site.pdf";
image.Save(outPath, pdfOptions);
```

## ขั้นตอนที่ 5: ตรวจสอบการส่งออก

ตรวจสอบว่าการส่งออกภาพ 3D ไปเป็น PDF สำเร็จ แสดงข้อความยืนยันพร้อมเส้นทางไฟล์ที่บันทึกไว้.

```csharp
Console.WriteLine("\n3D images exported successfully to PDF.\nFile saved at " + MyDir);
```

## ปัญหาทั่วไปและวิธีแก้

- **หน้าเปล่าใน PDF** – ตรวจสอบว่าค่า `PageWidth` และ `PageHeight` ตรงกับมิติของ DWF ต้นฉบับ.  
- **เลเยอร์หาย** – ตรวจสอบว่า `RasterizationOptions` มี `VectorRasterizationOptions` ตั้งค่าเป็น `true` เพื่อรักษาข้อมูลเวกเตอร์.  
- **ข้อผิดพลาด out‑of‑memory กับไฟล์ขนาดใหญ่** – เปิดใช้งาน `LoadOptions` พร้อม `MemorySaving` เพื่อประมวลผลไฟล์ในโหมดสตรีมมิ่ง.
