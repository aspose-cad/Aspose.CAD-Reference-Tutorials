# วิธีส่งออก CAD เป็น PNG – ส่งออกไฟล์ IFC ด้วย Aspose.CAD

## บทนำ

หากคุณต้องการ **how to export cad to png** Aspose.CAD for .NET มีวิธีที่เชื่อถือได้และไม่ต้องเขียนโค้ดเพื่อแปลงโมเดล IFC (Industry Foundation Classes) ให้เป็นภาพ PNG raster ที่คมชัด ในบทแนะนำนี้เราจะเดินผ่านขั้นตอนทั้งหมด—from การติดตั้งไลบรารีจนถึงการบันทึก PNG สุดท้าย—เพื่อให้คุณสามารถรวมการแปลงนี้เข้าไปในแอปพลิเคชัน .NET ใดก็ได้ด้วยความมั่นใจ

## คำตอบอย่างรวดเร็ว
- **ไลบรารีที่จัดการการแปลงคืออะไร?** Aspose.CAD for .NET.
- **รูปแบบแหล่งที่มาที่รองรับ?** IFC (Industry Foundation Classes) files.
- **รูปแบบภาพเป้าหมาย?** PNG, with full control over size and resolution.
- **เวอร์ชัน .NET ขั้นต่ำ?** .NET Framework 4.5+ or .NET Core 3.1+.
- **ข้อกำหนดใบอนุญาต?** A valid Aspose.CAD license for production use.

## “how to export cad to png” คืออะไร?

วลีนี้หมายถึงกระบวนการแปลงไฟล์รูปแบบ CAD เช่น IFC ให้เป็น Portable Network Graphics (PNG) raster images การแปลงนี้ทำให้การดู, การแชร์, และการฝังภาพ CAD บนหน้าเว็บ, เอกสาร, หรือรายงานเป็นเรื่องง่าย โดยให้รูปแบบที่มีน้ำหนักเบาและรองรับอย่างกว้างขวาง ซึ่งรักษาความคมชัดของภาพโดยไม่ต้องใช้โปรแกรมดู CAD เฉพาะ

## ทำไมต้องใช้ Aspose.CAD สำหรับการแปลงนี้?

Aspose.CAD รองรับ **50+ CAD and BIM formats** และสามารถประมวลผลโมเดล IFC หลายร้อยหน้าโดยไม่ต้องโหลดไฟล์ทั้งหมดเข้าสู่หน่วยความจำ มันให้การแปลงที่เร็วและใช้หน่วยความจำน้อยบนฮาร์ดแวร์เซิร์ฟเวอร์มาตรฐาน โดยอัตโนมัติจัดการเลเยอร์, ความหนาของเส้น, และการแมปสี พร้อมตัวเลือกการกำหนดค่าที่หลากหลายสำหรับคุณภาพและขนาดของผลลัพธ์

## นำเข้า Namespaces
เมื่อเตรียมข้อกำหนดครบแล้ว ให้นำเข้า namespaces ที่จำเป็นสำหรับทำงานกับ Aspose.CAD ในโครงการ .NET ของคุณ

```csharp
using Aspose.CAD.ImageOptions;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using Aspose.CAD.FileFormats.Ifc;
```

## วิธีส่งออก CAD เป็น PNG?

`IfcImage` แสดงถึงภาพ CAD แบบ IFC ที่สามารถ rasterize เป็นรูปแบบ raster เช่น PNG โหลดไฟล์ IFC ของคุณด้วย `new IfcImage("source.ifc")` ตั้งค่าการ rasterization ผ่าน `RasterizationOptions` ตั้งค่าที่เฉพาะของ PNG ด้วย `PngOptions` และสุดท้ายเรียก `Save(outputPath, pngOptions)` กระบวนการแบบ end‑to‑end นี้จะแปลงโมเดล CAD เป็น PNG ความละเอียดสูงในไม่กี่บรรทัดของโค้ด พร้อมจัดการเลเยอร์, สี, และความหนาของเส้นโดยอัตโนมัติ

## ขั้นตอนที่ 1: โหลดไฟล์ IFC
คลาส `IfcImage` โหลดโมเดล IFC และเตรียมพร้อมสำหรับการ rasterization

```csharp
string MyDir = "Your Document Directory";
string sourceFilePath = MyDir + "example.ifc";
using (IfcImage cadImage = (IfcImage)Image.Load(sourceFilePath))
{
```

ในขั้นตอนนี้เราจะเริ่มต้นอ็อบเจกต์ Aspose.CAD `IfcImage` และโหลดไฟล์ IFC เข้าไป

## ขั้นตอนที่ 2: ตั้งค่า Rasterization Options
คลาส `RasterizationOptions` กำหนดวิธีการแปลงข้อมูลเวกเตอร์เป็นภาพ raster รวมถึงความกว้าง, ความสูงของหน้า, และสีพื้นหลัง

```csharp
    CadRasterizationOptions rasterizationOptions = new CadRasterizationOptions();
   
    rasterizationOptions.PageWidth = 100;
    rasterizationOptions.PageHeight = 100;
```

กำหนด rasterization options เพื่อกำหนดความกว้างและความสูงของหน้าสำหรับผลลัพธ์ PNG

## ขั้นตอนที่ 3: ตั้งค่า PNG Options
คลาส `PngOptions` เก็บการตั้งค่าที่เฉพาะของการส่งออก PNG เช่น ระดับการบีบอัดและความลึกของสี

```csharp
    PngOptions pngOptions = new PngOptions();
    pngOptions.VectorRasterizationOptions = rasterizationOptions;
```

สร้าง PNG options และเชื่อมโยงกับ rasterization options ที่กำหนดไว้ก่อนหน้า

## ขั้นตอนที่ 4: ระบุเส้นทางการส่งออก
เส้นทางการส่งออกกำหนดว่าภาพ PNG ที่สร้างขึ้นจะถูกบันทึกไว้ที่ไหน

```csharp
    // Set output path as well
    string outPath = sourceFilePath + ".png";
    cadImage.Save(outPath, pngOptions);
}
```

กำหนดเส้นทางการบันทึกไฟล์ PNG โดยให้ชื่อไฟล์เดียวกับไฟล์ต้นฉบับและต่อด้วยส่วนขยาย ".png" สุดท้ายบันทึกภาพที่แปลงแล้ว

## ปัญหาทั่วไปและวิธีแก้ไข
- **ฟอนต์หรือสไตล์เส้นที่หายไป:** ตรวจสอบให้แน่ใจว่า IFC ต้นฉบับอ้างอิงทรัพยากรที่จำเป็นทั้งหมด; Aspose.CAD จะฝังทรัพยากรที่หายไปเมื่อเป็นไปได้
- **ไฟล์ขนาดใหญ่ทำให้หน่วยความจำพุ่งสูง:** ใช้คุณสมบัติ `MemoryLimit` บน `RasterizationOptions` เพื่อจำกัดการใช้หน่วยความจำ
- **สีไม่ถูกต้อง:** ตรวจสอบว่าการกำหนดค่าสีใน IFC ตรงตามสคีมาของ IFC; Aspose.CAD ปฏิบัติตามการแมปสีมาตรฐาน
